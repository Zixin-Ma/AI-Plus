# 工业模型在公开投影上的持续优化

2026 年 11 月 25 日，BJTU 校赛开发记录。赛方提供的三个训练起点都包含已经训练的 CPU 模型。系统从平台指定的父产物续训。Qwen/Qwen3.8-27B 按校赛允许的基础模型路径接入，通过 SDK 读取实验结果并决定部署或保留。

上述工作用于确定实验设计。代码只依赖赛方的 SDK、基线及 NumPy，CPU 和内存预算按 SDK 1.0.4 的 2 核、4 GiB 设计。

## 三项任务与结果

| 公开任务 | 训练行 / 验证行 | 静态基线 | 十轮 CPU 对照选中 | 真实 27B 联调选中 |
| --- | ---: | ---: | ---: | ---: |
| A 气体分类，Macro-F1 ↑ | 445 / 1,244 | 0.714030 | 0.725782 | 0.724210（3 轮） |
| B 轴承寿命，RMSE 分钟 ↓ | 7,032 / 1,679 | 681.1598 | 649.7214 | 649.7214（3 轮） |
| C 发动机寿命，RMSE 循环 ↓ | 113,089 / 23,049 | 52.8686 | 48.6173 | 52.8686（初版 3 轮），48.7802（修正后从官方起点重新跑 1 轮） |

CPU 对照仅使用验证指标决定部署，用于测量候选序列与回退保护。相对静态基线，最终版本十轮对照的 A 增加 0.01175 个 Macro-F1 单位，B 和 C 的 RMSE 分别下降约 4.62% 和 8.04%。验证划分也参与选型，因此不能用这些结果替代隐藏测试。B 的 1,679 条验证行中有 1,515 条来自同一根轴承，按分钟聚合的 RMSE 对这根轴承尤其敏感。

## 观察与决策

A 的特征 41（从零编号）在验证与训练的均值差约为训练标准差的 11.46 倍；传感器相对响应和余弦相似度为校正提供另一组特征。B 的水平频谱质心偏移约 1.05 个训练标准差。C 的最大全局均值偏移约 0.03 个标准差，但不同工况仍可具有不同传感器基准。以上是可复核的分布描述，不能单独确定漂移原因。

每轮恢复父检查点保存的网络、Adam 状态和标准化参数，先更新基础 MLP，再拟合带正则的线性残差系数。相同训练数据上比较普通、收缩及稳健更新，通过公开验证选择本轮上传候选。已有残差分支的基函数在续训时保持固定，系数可以增量更新；纯 Adam 作为消融。Qwen 只接收聚合数据并做部署判断。非正增益或不可解析回复均保留父模型。平台支持候选分块上传，预测使用单条输入并同步刷新输出。

初版 C 提示把多个候选指标放在一起，27B 三次错误说明 RMSE 变高。修正提示明确展示父模型、候选和带符号的收益，单次真实复核正确采纳，随后将该提示纳入提交镜像。完整运行记录保留首版失误和修正。每个数据集首轮均可从原始基线复现。各轮均沿用公开投影，十轮演练覆盖续训路径；平台阶段数据和隐藏测试的结果以平台回执为准。

## 成本与复现

10 次开发推理回执共 3,176 个输入和 410 个输出 token，按[PyTRIO 公开未缓存价](https://pytrio.com/home/pricing)估算约 0.0204 元。此为推理估算，账单应以账号结算为准。正式镜像每轮发起一次真实模型调用，关闭思考，输出上限为 160 token。宿主添加官方提示并负责计量。

[公开实验项目](https://swanlab.cn/@Zixin-Ma/ai-plus-campus-rsi)记录 CPU 初版、最终十轮对照、九次初版 Qwen 联调以及 C 的修正复核。每条实验含候选和父模型指标、更新步数、漂移摘要、决策理由和用量。镜像验证另覆盖 A、B、C 各两个连续 SDK 轮次及逐行预测。开发实验和回执回放均不占用比赛平台的试运行或正式次数。
