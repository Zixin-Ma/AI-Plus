# 发动机寿命预测实验

训练输入包含三项运行设置和当前循环的 21 路传感器。仅在分组评估时读取发动机编号和 FD 子集标识。初始训练包包含 113,089 条公开训练行，公开验证集含 106 台发动机、23,049 行。全部实验使用 BJTU 单进程 CPU，OpenBLAS 单线程。

同一传感器值在不同运行设置下可对应不同健康状态。2026 年的 C-MAPSS 消融研究发现，工况标准化、特征选择和窗口设计会影响寿命预测。另一项整机留出研究发现，RMSE 改善有时伴随不对称代价上升。我们据此比较工况内标准化的不同残差模型，并同时测量 RMSE 与 NASA 总分。赛方预测接口一次提供当前循环的输入，所以模型只编码该次测量。[预处理消融](https://doi.org/10.1016/j.array.2026.100919) [工况标准化复现实验与代码](https://arxiv.org/abs/2611.28759)

## 候选筛选

在官方起点的较小 Adam 续训上，取训练行学习各工况均值、方差，比较工况内线性、二次项、径向核、树集成、寿命分箱高斯后验、监督退化方向与小型神经网络。下表列出各方法在公开验证上的代表配置，RMSE 均以循环计。

| 候选 | RMSE | 最差 FD 子集 RMSE |
| --- | ---: | ---: |
| 官方检查点 | 52.869 | 63.237 |
| V1 十轮公开演练选中 | 48.617 | 58.678 |
| 工况内线性残差 | 49.904 | 59.495 |
| 工况内二次残差 | 49.596 | 59.084 |
| 工况内核残差，32,768 行 | 48.794 | 58.663 |
| 对称树 144 棵 | 49.68 | 60.47 |
| 工况内寿命后验与 MLP 加权 | 50.86 | 62.51 |
| 监督退化轴与 256 个共享余弦特征 | 48.14 | 57.74 |
| 单隐层残差网，48 单元，20 个 epoch | 47.18 | 56.16 |
| 单隐层残差网，64 单元，35 个 epoch | 47.01 | 56.18 |

48 单元网络在 24,576 条训练行上学习官方父 MLP 的误差。一次预测使用传感器工况归一化值、父 MLP 输出和工况编码。开发折中，未经约束的网络对部分发动机出现过量寿命修正。在同一公开验证设置中，保持网络固定、限制单次修正为 ±65 循环，RMSE 从 47.18 降至 46.83，NASA 总分从 3.87×10¹⁰ 降至 1.49×10⁹。对所有真实寿命和预测绝对值均保留原任务定义。较强硬截断预测上限在包含长寿命发动机的第一个整机折中增加了 RMSE，最终只限制残差幅度。

## 冻结复验

使用实际 V2 集成的首轮续训参数，在相同公开行上运行 V1 和 V2。五个整机折各自从所保留的训练发动机重新拟合初始 MLP（15 个 epoch），避免官方初始模型预先见过留出发动机。折 3 和折 4 在选定网络与残差限幅后首次打开。V1 首轮使用该折验证行选候选，V2 使用固定残差配置。逐 FD 子集的最差 RMSE 是跨环境诊断，赛方正式的阶段分另行计算。

| 评估集 | V1 首轮 RMSE | V2 首轮 RMSE | V1 最差 FD 子集 | V2 最差 FD 子集 |
| --- | ---: | ---: | ---: | ---: |
| 整机折 0 | 49.757 | 49.226 | 68.953 | 68.946 |
| 整机折 1 | 51.517 | 50.792 | 60.696 | 60.260 |
| 整机折 2 | 49.932 | 48.701 | 55.197 | 54.990 |
| 保留整机折 3 | 57.897 | 56.409 | 71.739 | 69.299 |
| 保留整机折 4 | 55.184 | 54.746 | 68.375 | 68.192 |
| 官方公开验证 | 48.780 | 46.810 | 58.827 | 56.015 |
| 移除高度 0 工况后测该工况 | 65.512 | 68.105 | 75.962 | 78.360 |
| 移除高度 25 工况后测该工况 | 147.458 | 117.240 | 162.206 | 131.785 |

公开验证 MAE 从 35.165 降到 33.155，NASA 总分从 3.876×10⁹ 降到 1.434×10⁹。按发动机配对、有放回地重采样 1,000 次，V2 减 V1 的 RMSE 差值的 95% 百分位区间为 [−2.697, −1.157]。五个整机折中有三个差值区间跨过零。工况删除压力测试可体现外推风险，尤其在占比最大的高度 0 工况完全缺失时。

排除 JSON 读取后，首轮训练、消融和同一全量公开验证合计 V1 消耗 2.110 CPU 秒，V2 消耗 0.531 CPU 秒。各自对 2,048 条相同输入逐条预测，重复五次取中位，每条 V1 为 69.86 微秒，V2 为 39.50 微秒。V2 逐行和批量数学输出最大绝对差 1.43×10⁻¹³；残差头的数组共 13,256 字节。平台报告还统计协议、解码、宿主预测和资源调度等费用，实际得分以赛方正式计量为准。

从校赛目录运行下列命令。JSON 输出位于服务器忽略目录 work/v2/engine/，含每折、每个 FD 子集、NASA、原始 CPU 值以及配对区间。开发筛选与冻结复验分别执行。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B V2/bench_engine.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B V2/bench_engine_confirm.py
```
