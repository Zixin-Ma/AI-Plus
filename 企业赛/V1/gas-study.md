# A 气体识别的路线选择与验证

企业赛分类器保留气体识别 MLP 的续训状态。两项新增证据分别来自训练样本在特征空间的局部差异，以及每种气体在不同采集条件下的类内变化。训练时，每类把已释放样本分为最多 16 个连续块，以块中心拟合高斯核岭回归。第二个分支使用 128 个对数响应，在每个类别上拟合三维仿射子空间，以到该空间的收缩距离评价单次测量。部署输出为 MLP 对数分数加上校赛两个判别分支之和的 0.4 倍，以及核分支和子空间分支之和的 0.5 倍。每次预测只使用单条输入与检查点内的数值数组。

类内低秩方向可吸收训练中已出现的部分浓度或响应变化。浓度并未作为训练标签，因此这些方向的物理含义无法逐项辨认。对气体漂移方向分解已有同行研究，较新的在线漂移评测也区分首批迁移和累积更新两种设置。这里的技术贡献集中在小型 CPU 检查点、多路线选型和阶段保护的组合。[类条件漂移建模](https://doi.org/10.1016/j.chemolab.2022.104549) · [2025 年时序漂移评测](https://arxiv.org/abs/2507.17071)

**补充数据的独立检验。** 一年漂移数据实际使用作者特征表的 624 条可读记录。基于前 12 个采集日的 215 条记录拟合原生 62 传感器分类器，在后 24 日的 409 条记录检验。使用原生电阻、相对差、起始斜率和恢复量，按仪器布局构造绝对与相对响应，各路线独立重训。24 个检验日依次分为三段，校赛得 0.5729、0.4804、0.4203，企业融合得 0.6502、0.5560、0.5821。以采集日为单位配对有放回重采样 4,000 次，融合减校赛的 Macro-F1 差的 95% 百分位区间为 [0.0621, 0.1633]。此区间反映这 24 日的经验波动，相邻采集日仍可能相关。[数据论文](https://www.nature.com/articles/s41597-025-05993-8) · [实验文件](https://zenodo.org/records/15681119)

DS-PS 检验了另一种仪器和浓度变化。按发布方定义从各 MATLAB 文件前 1,536 列还原传感器、负载电阻和加热相位，利用基线、瞬态和稳态摘要。选取乙醇、丙酮、丁酮的 20–120 ppm 全部 180 次暴露。每种物质的重复 1–6 用于训练，重复 7–10 用于测试，同一重复全部浓度在一侧。各类 0 ppm 测量均为干空气，排除在三分类任务外。低、中、高浓度的 Macro-F1 中，校赛依次为 0.6645、0.4453、0.4714，融合为 0.6645、0.4041、0.4222。这套装置的中高浓度是明确的负迁移实例，因此上机前需要同型号仪器和独立浓度范围的留出复核，尤其要检查弱类召回。两套外部试验均单独拟合，比赛镜像的训练参数来自赛方公开训练数据。[2026 年 DS-PS 原始发布](https://zenodo.org/records/19557093)

**资源开销。** 同机单线程，固定 445 条训练样本、256 条逐样本推理、五次重复中位数。校赛与企业气体头的训练 CPU 时间约 4.8 和 15.1 毫秒，预测约 115 和 179 微秒/条，压缩头大小为 47,880 和 145,704 字节。计时只覆盖分类模块。平台客观资源项还包含完整训练流程和宿主计量。

**复现。** 项目根目录下用 ai-plus 环境执行 `OPENBLAS_NUM_THREADS=1 python -B 企业赛/V1/gas_study.py`；用带 SciPy 的系统 Python 执行 `OPENBLAS_NUM_THREADS=1 /usr/bin/python3 -B 企业赛/V1/gas_study.py --ds-ps`。记录分别保存于 `企业赛/work/gas-study/gas-ablation.json`、`企业赛/work/gas-study/ds-ps.json`。中间发布量回放使用主程序 `benchmark.py A enterprise 0`。源码只使用 NumPy 实现分类器，SciPy 仅用于开发环境读取补充 MATLAB 文件。
