# 企业 V4 气体识别 · 跨日复验与单条预测

V3 在一年电子鼻上用前 12 个采集日重拟合，随后 24 日的 Macro-F1 为 .5334。V4 在相同样本及选型规则下达到 .6025。为区分已知窗口与本轮保留的未来窗口，本轮先固定按日向前协议，再评估末段 8 日。在这 143 条按日保留的记录上，V3 与 V4 分别为 .6385、.6458。代码通过比赛原有单条输入接口，预计算只依赖已加载的模型权重。

## 已知窗口与按日留出

一年电子鼻有 62 个氧化物传感器。作者提供原始阻值、相对变化、响应初始斜率与恢复指标及特征提取 notebook。我们以样本自身的平均阻值归一化初始斜率，配合相对变化与恢复值，降低通道乘性变化带来的干扰。归一化在同一样本内完成。采集日只用于划分训练、选型及验证，以及外部实验中确定各类训练样本的时间次序。[原始研究](https://doi.org/10.1038/s41597-025-05993-8) · [数据与特征提取代码](https://zenodo.org/records/15681119) · [Du 等，2026 年跨日漂移与置信校准研究](https://analyticalsciencejournals.onlinelibrary.wiley.com/doi/10.1002/cem.70148)

先将 36 个日期排序并从 0 开始编号。所有时间界限在 day-plan.json 中先行记录。每个开发窗口使用更早的日期拟合，在随后互斥的两个日期比较候选，按该验证窗口 Macro-F1 选头，再用全部已开放历史重拟合，最后使用连续四天测试。

三个开发窗口等权平均由 .6647 升至 .6949。方案与生产模块指纹在 protocol.json 落盘之后开启 V4 末段，选型仅用第 24–27 号采集日的 50 条样本。两版使用前 28 个日期的 481 条做最终重拟合。对末段前后两个四日块分别测得 .5726 → .5923 和 .6843 → .6843。4,000 次按采集日配对重抽样并重算 Macro-F1，末段 V4 减 V3 的 95% 百分位区间为 [−.0003,+.0245]，与小幅改善和近零变化均相容。不同开发期之间允许较早测试日进入之后的已知历史。末段是为本次 V4 研究保留的窗口，V3 历史报告曾公开过后 24 日的整体结果。

**同口径历史对照。** 沿用前 8 日初训、后 4 日选型、前 12 日共 215 条重拟合的协议，之后 409 条依次测试。V3 选中 tail，V4 选中加入动态响应证据的 independent，Macro-F1 从 .5334 升至 .6025，按日配对区间 [+.0307,+.1106]。与末段复验相比较，较大提升与起始日期、当时可用的训练量及所选分支有关。

## 部署机制与技术路线

比赛传感器包含 16 组稳态响应和六个瞬态摘要。对每个传感器取归一化稳态响应以及六个瞬态量对稳态偏移幅度的比，分母下限为 1。每维减训练中位数并按 MAD 缩放，再做反双曲正弦变换。分离单样本内的跨通道均值和通道差值，使响应模式与整体强度可以分别进入核回归。每类按已释放样本的源顺序构造最多六个均值原型，用类别均衡的核岭回归拟合六类得分。[UCI 气体阵列的源特征定义](https://archive.ics.uci.edu/dataset/224/gas+sensor+array+drift+dataset) · [scikit-learn 的核岭回归实现](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/kernel_ridge.py)

只在 V3 的 independent 分支加入这个模型。将物理分支六类得分减去行内最高值，记为 s，将前两名原始分数差记为 g。修正量为 clip(8s,−6,0) × clip(g/.4,.25,1)。物理分支难以区分前两名时，修正强度随之减弱。原有 tail 分支、父检查点与宿主独立测量链路保留。新分支的统计量只从训练样本估计，部署每次提供一条标准输入，既不需要采集日期，也不累积待测行。

一年电子鼻以其 62 通道布局重拟合上述通用核回归。DS-PS 使用各暴露试验基线校正后的稳态幅度以及瞬态/稳态幅度，按传感器样本原生 layout 提取。三种气体、六个非零浓度，每组前 4 个重复拟合、随后 2 个选型、前 6 个重拟合、最后 4 个测试。72 条留出重复上 V3 为 .5077，V4 为 .5664。三个浓度分组在 V4 分别为 .6645、.4347 和 .5902。两个外部实验均重新估计其仪器参数，评估的是方法迁移，比赛镜像不加载外部仪器数据或拟合权重。[DS-PS 数据与采集协议](https://zenodo.org/records/19557093)

收益和回落以各流相同静态起点的 Macro-F1 为参照。增长池拆分 6 的回落由 7.61 增到 23.31 点，是主要不利结果。固定池拆分 7 的 V4 最低收益仍为 −1.89%。两条路径上的质量取舍须分开观察。8、9、10 的全局顺序与正式隐藏评分均不参与分项选型。

**全量公开首轮。** 实际训练入口执行同一条离线 refit/half 计划，宿主替身独立加载候选，在同样的 1,244 条公开验证样本计量。父模型 Macro-F1 为 .71403。两版均采用权重 .35 的 independent，V3 与 V4 的 F1 为 .86232 → .88905，最弱类召回 .57798 → .78659，候选 NPZ 合计 228,060 → 248,544 字节。

**单条预测。** 为兼容的权重预计算二次型的常数及线性项、原始响应到类内子空间的中心投影和归一化倒数。同一行的响应特征及相同尺度的归一化结果在判别、核预测和曲线间共享。每个已加载模型有一份不可变编译结果，各行只消费自身输入。对 1,244 条公开行与 13 条零值、强弱幅度及符号翻转压力行验证，V3、V4 两类头均零类别变化，编译前后六类分数最大绝对差 1.64 × 10⁻¹³。V2 的两种旧头显式回退原始代码，输出差为 0。

同一 CPU 上交替五次，原始与编译的 V4 tail 为 184 → 134 微秒，independent 为 368 → 244 微秒。另以完整单行 JSON 预测入口、相同逻辑 CPU、两版轮换三次，取中位数。增长顺序 0 的单条 CPU 由 544 降为 442 微秒，官方固定顺序 0 为 694 → 449 微秒。十轮训练 CPU 分别为 .958 → 1.011 秒和 1.002 → 1.206 秒。对应的检查点合计分别为 1.798 → 1.759 MB 和 2.280 → 2.485 MB。新的证据分支增加拟合和存储成本，预测阶段的代数预计算降低了单行延迟。

## 复验入口

在服务器企业赛 V4 源码目录，设置 OPENBLAS_NUM_THREADS=1、OMP_NUM_THREADS=1 后使用 ai-plus 的 Python 并加 -B。运行 gas_v4_study.py development 重建三窗研究，terminal 读取冻结配置重建封存两段，paired-days 重新计算按日置信区间与 V3 历史窗口。DS-PS 的 MATLAB 读取使用 /usr/bin/python3 -B gas_v4_study.py ds-ps。参数 v3、frozen 与各路线名称执行 0–7 开发回放，full-v3、full-v4 运行全量首轮，hot 验证兼容性与单条性能，cost 复测十轮进程成本。工作记录在企业赛/work/v4/gas。外部源数据无需导入比赛镜像，整个分项运行只使用 CPU 和受控协议回复。
