# 企业赛 V4 轴承验证

## 冻结决定

保留 V3 的寿命模型、模型混合和历史记忆保护。V4 只复用重复的训练计算，并为单条振动快照编译专用推理函数。用同一 V3 控制器、同一批公共审计样本和同一确定性评审，在 8 个已公开的划分、3 种流程上共回放 240 轮。V3 与 V4 每轮选中的产物、专家权重和专家类别全部一致，每阶段 RMSE 的最大差为 0。完整公开首轮两版均采用 0.65 权重，RMSE 同为 507.8345 分钟，决策端模拟调用两次，候选模型文件均为 42,449 字节。

## 单行实现

冻结产物装载时，`prepare_inference(model, head)` 只执行一次。它绑定归一化参数、随机投影、三个转速工况的预插值曲线及高频冲击上下界。对两轴的频率读数，用标量计算四类机械特征阶次的倍频相容度，两个轴共享已计算过的频率相容度。每个候选输入只计算一次工况权重和骨干寿命。成熟头的高频冲击达到训练上限时，额外寿命修正系数已为零，可直接返回此前的专家结果。该快捷路径也处理两个冲击分位数完全相同或间距小于 10⁻⁸ 的情况。缓存对象只包含频率证据与不可变产物参数。常规批量预测仍供训练与评审使用。

拟合时，阶次先验与寿命秩曲线共享同一份训练频率证据，尾部保护与寿命曲线共享骨干预测。完整训练、截短寿命标签和整台 Bearing3_2 留出三种设置的所有头参数与 V3 逐元素一致。头数组共 6241 字节。

## 真实推理入口

相同的已存续训骨干和 0.65 混合头，带 −12.5 分钟测试偏移。1679 条真实公开输入经 `contest_submission.predict` 完成特征提取、校验、专家推理、静态混合和 JSON 输出编码。单 CPU 线程，七次全量测试取中位。冷装载包括重新读取模型文件，操作系统文件缓存保持可用。两版最大输出差为 2.28×10⁻¹³ 分钟。

| 项目 | V3 | V4 |
|---|---:|---:|
| 热入口每行 CPU 时间 | 198.86 微秒 | 66.61 微秒 |
| 热入口吞吐 | 5029 条/CPU 秒 | 15012 条/CPU 秒 |
| 重新装载产物并产出首条 | 7.755 毫秒 | 7.903 毫秒 |
| 裸专家热单行，独立微基准 | 83.63 微秒 | 27.24 微秒 |

## 最差阶段与替代方案

每行取八条十轮流的均值。最差阶段列先取每条流最差一轮，再对八条流取平均。收益为相应审计阶段相对静态模型的 RMSE 降幅。回撤为曾见阶段相对历史最优的最大下降。延迟为切换后恢复所需轮数。逐批训练逐步开放标签，固定池保持完整训练池并轮换验证阶段，fresh 在重访某个阶段时使用新的选择样本。

| 流与方案 | 平均收益 | 最差阶段 | 回撤 | 恢复延迟 |
|---|---:|---:|---:|---:|
| 逐批训练，V3 / 冻结 V4 | 2.04% | −4.37% | 0.129 | 0.300 |
| 固定训练池，V3 / 冻结 V4 | 27.68% | +3.17% | 0.534 | 0 |
| fresh，V3 / 冻结 V4 | 1.20% | −11.14% | 0.171 | 0.253 |
| 固定池，额外提供 0.85 专家权重 | 29.34% | +3.00% | 0.585 | 0 |
| 固定池，随冲击支持度额外收缩 | 27.52% | +3.04% | 0.531 | 0 |
| 逐批训练，低秩蒸馏学生 | 0.94% | −3.63% | 0.159 | 0.309 |
| 固定训练池，低秩蒸馏学生 | 5.95% | −7.58% | 0.259 | 0.122 |
| fresh，低秩蒸馏学生 | −0.45% | −6.71% | 0.221 | 0.297 |

增加 0.85 混合权重提高了固定池总体收益，同时降低最差阶段、增加回撤。支持度收缩将成熟头在中等冲击区间的修正部分退回 V2 专家，固定池总体与最差阶段均略降。这两项在逐批训练和 fresh 设置下没有改变汇总成绩。冻结 V4 在这八个已知划分中的绝对最差单轮分别为逐批 −21.08%、固定池 0%、fresh −28.21%。

蒸馏学生仅从本轮训练集取最多 1536 行，学习 V3 专家与父骨干的预测差。学生使用与教师相同的对数特征及归一化，将残差压缩为单层岭回归。头从 6241 降至 824 字节，在该次配对微基准中单行从 43.32 降至 21.23 微秒。但完整公开裸头 RMSE 从 437.80 上升至 604.90 分钟，且固定池的最差阶段转负。该方案只保留在研究脚本中。逐轮数据位于 `reference/`、`frozen/`、`weight/`、`support/`、`student/`，蒸馏的公开结果和速度见 `student.json`。

## 等价性与复现

逐行核对 7032 个官方训练快照、1679 个验证快照、761 个 FEMTO 快照及 129 个 KAIST 快照。使用完整与截短标签头、整台留出头，以及在 FEMTO 标注上拟合的校准头。另对校赛、企业 V1、企业 V2 的旧头验证单行入口。146 条合成行覆盖半谐波四舍五入边界两侧、负频带与零频带、秩插值结点和高频门槛，并以正常、完全重合及相距 10⁻¹⁰ 的冲击分位分别验证。跨全部比较的最大绝对预测差为 1.84×10⁻¹¹ 分钟。静态混合权重 0、0.15、0.65、1 分别带寿命偏移核对，最大差为 1.03×10⁻¹² 分钟。维度错误、NaN 与无穷输入均在共享入口被拒绝。

在服务器仓库根目录的 ai-plus Python 环境执行。研究入口只接受已知 split 0–7，调用公开回放的确定性评审。输出目录为 `企业赛/work/v4/bearing`。部署源 SHA-256 为 `db2e812876a683ae25e6259ae8700f9182cc423a7967ec29b86285ee4ee81efa`。
