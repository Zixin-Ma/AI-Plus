# 发动机任务｜用训练期寿命分层监督改善薄弱阶段

企业 V3 在开发顺序 5 的第十轮面对最早寿命阶段时，RMSE 比同流静态起点高 3.92%；开发顺序 3 的第六轮同一阶段高 6.68%。在固定官方训练池中，低谷却常出现在寿命第二个四分之一。简化为对所有高寿命预测统一加减固定偏移，会把两个阶段的利益放在相反方向。

## 已冻结的任务头

每次在当轮可见训练样本上计算剩余寿命第 20、45、70 百分位。原有神经头继续预测骨干对寿命的连续残差；同一隐藏层同时学习三个二元目标，分别判断真实寿命是否低于相应阈值。连续目标使用均方误差，三个二元目标使用平均二元交叉熵。首次/新增池的辅助损失权重为 0.7；相同训练池已有父任务头时用 0.2，减轻重复拟合同一组离散边界的影响。实际比较了两个固定强度和两种稳定池调度。

部署时仅保存连续残差的一列读出权重。线上输入仍是 21 路传感器和 3 路运行设置；每次预测沿用 V3 的工况归一化、65 循环残差界、尾部幅度控制及 50% 延寿量约束。寿命阈值、二元标签、设备编号、真实阶段不进入预测。训练阶段用 FP32 和合并矩阵计算四个目标；保存及服务端预测使用双精度系数。`prepare_inference(model, head)` 缓存固定投影所需数组，复用骨干的 `predict_one`。

近期的退化阶段研究比较了阶段几何、终端覆盖与提前告警，按设备隔离的评估表明，整体误差和紧急区误差需要分别报告。这里把寿命区间作为训练监督，并另审计高估与低估部分的 NASA 代价。三列二元概率没有进入部署，也不承担区间覆盖保证。 [阶段识别及留出研究](https://doi.org/10.3390/s26227305) · [整机分组验证与安全校准](https://doi.org/10.3390/machines14101124) · [非对称寿命区间](https://www.papers.phmsociety.org/index.php/ijphm/article/view/4724)

## 同一控制器下的配对结果

保持 V3 的控制器行为、初始检查点、阶段顺序和公开数据分区一致，单独比较 V3 与 V4 发动机头。增长和固定池均用开发拆分 0–7，fresh 用拆分 3–7，每条流十轮。三种场景都按流等权。增长池从每条公开轨迹的 55% 逐轮释放至完整，固定池直接加载官方起点和完整训练池，fresh 每次重访阶段更换选型样本。设备留出审计与选型互斥。

|场景|均值收益 %|每流低谷均值 %|全局最低 %|历史回落点|恢复轮数|
|---|---:|---:|---:|---:|---:|
|增长池，8 条流|18.559 → 18.582|−2.388 → −2.024|−6.685 → −5.752|7.887 → 7.843|0.228 → 0.228|
|固定池，8 条流|16.539 → 16.795|2.451 → 2.358|−4.929 → −4.326|1.865 → 2.700|0.078 → 0.078|
|fresh，5 条流|18.777 → 18.854|−2.124 → −1.658|−6.685 → −5.752|8.320 → 9.083|0.125 → 0.125|

V3 头的 21 条独立回放与归档 V3 的每轮阶段收益一致。固定控制器下，增长池全部最低阶段提升 0.93 个百分点，固定池提升 0.60 个百分点。固定池每流低谷均值、固定池和 fresh 的历史回落仍有退化。整套 V4 更换控制器后，新增收益需以冻结复验衡量。本组实验限定开发拆分，多个顺序复用公开来源。

DS02 巡航 RMSE 为 7.885 → 7.477，非巡航为 8.608 → 8.156。内部各折 RMSE 的差异很小，按 1,000 次整机自助抽样，均方误差差的百分位区间分别为 [−9.06, +11.78]、[−4.17, +26.33]。DS02 的两台机差异方向一致，区间 [−9.10, −5.44]，外部审计仅覆盖两台独立设备。

NASA 以 e＝预测减真实，高估取 exp(e/10)−1、低估取 exp(−e/13)−1。固定池末四分之一高估超过 30 循环的比例 7.32% → 6.79%，但所有行的高估代价仍从 2.127×10⁸ 增至 2.272×10⁸。DS02 高估代价从 15,216 降至 13,694，低估代价从 1,416 增至 1,556。现场应同时关注过度延寿、提前检修以及末段误差。
