# A · 漂移气体阵列的受限外推与有界证据

气体阵列的同一响应既进入 MLP，又可用来估计浓度相关的响应曲线。两类头共享骨干时，直接叠加两次骨干输出会放大原有类别偏差。V3 保留两个可独立部署的头。第一头限制未知幅度下的曲线外推，第二头只让传感器曲线提供有上限的补充证据。开发的十条公开十轮流中，逐轮释放训练数据的平均阶段收益由 21.45% 升至 25.17%，固定官方起点的平均阶段收益由 15.75% 升至 18.43%。

## 传感器假设与拟合

每条记录含 16 个传感器的稳态电阻变化、归一化变化以及三种时间常数的上升和下降响应，共 128 维。我们保留 V2 的相邻通道配对、对数幅度、动态差分和类内低秩投影。使用稳态响应的平均对数幅度作为可观测的强度代理。不同物质、设备灵敏度与老化都会改变这一代理，其取值不能直接换算为浓度。[UCI 原始特征与采集说明](https://archive.ics.uci.edu/dataset/224/gas+sensor+array+drift+dataset) · [2026 年基于器件响应的跨电子鼻识别研究](https://doi.org/10.1016/j.snb.2025.139138)

- **tail** 用已释放训练样本拟合每类二次响应曲线，在该类幅度的第 5 至第 95 百分位内沿用拟合曲线。区间外沿边界切线延伸，最多半个训练幅度标准差。设 24 维投影中的类条件残差平方为 d，使用 24 log(1+d/24) 压缩异常残差的影响。对原始响应的低秩类内残差同样作 log1p 变换。该损失借用厚尾分布对数项的形式，输出用于类别判别。训练与部署均以单行可观测量计算。[SciPy 多元 t 分布的原始实现与密度定义](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.multivariate_t.html)
- **independent** 以 V2 的核岭、共享协方差判别、相对响应判别和 MLP 为主分类器。对未限制外推的原曲线提取额外传感器分数，先扣除共有骨干项，再减去该行最高传感器分数并截断到 [−4,0]。每类最多获得 4 个对数单位的相对修正。训练与推理复用同一低秩原始响应分量，只拟合两个候选，每次上传一个经当轮公开验证选中的候选。新增参数用 float64 拟合并以 float32 存档。旧版两种头均可加载。
- 每轮保留对父模型与静态参考的公开比较。下列分项试验固定控制器策略，独立核查分类头的贡献。工业系统的规划复用等变更另由总实验评估。

## 同起点的开发复验

五个公开顺序各运行十轮。每条流的选型行和审计行互斥，各顺序共享公开样本。行内分期分组不进入预测。所有候选仅使用已释放训练行拟合。新鲜训练池按同一类样本的原始次序从 55% 扩展到 100%。固定训练池在十轮均使用官方检查点起步时的完整公开训练集。阶段收益为相对静态起点的 Macro-F1 改善率。历史回落是已出现阶段相对自身历史最高收益的最大降幅。恢复延迟到重新获得非负收益时结束，阶段结束时截尾。

**官方起点全量公开首轮。** 实际调用生产训练与候选序列化入口，宿主替身用相同的 refit/half 回复，重新加载上传产物，使用全部 1,244 条公开验证行。两版从相同父模型 F1 .71403 开始。V2 采用 0.35 权重的旧判别头，得到 .81711，最弱类召回 .46789。V3 采用权重 .35 的 independent，得到 .86232，最弱类召回 .57798。六类分数的单行与批量最大偏差小于 1e−12。真实网关用量由另外的网关验证记录计量。

## 机制消融

| 路线 | 增长池均值 / 最差均值 / 回落点 | 固定池均值 / 最差均值 / 回落点 |
|---|---:|---:|
| 企业 V2 | 21.45 / 11.85 / 11.81 | 15.75 / −5.58 / 17.77 |
| 模拟各通道 10% 对数增益扰动 | 21.59 / 11.20 / 13.19 | 13.91 / −1.73 / 32.23 |
| 经验收缩条件判别替代曲线 | 6.40 / −9.23 / 12.52 | 15.75 / −5.58 / 17.77 |
| 幅度分组多核候选与旧头并列 | 5.24 / −9.09 / 22.90 | 16.73 / −2.52 / 24.33 |
| 只限制曲线外推 | 19.60 / 6.35 / 12.45 | 15.75 / −5.58 / 17.77 |
| 受限外推加厚尾残差，沿用旧判别头 | 24.76 / 15.20 / 19.77 | 15.75 / −5.58 / 17.77 |
| 两路曲线，有界投票仍计入共同骨干 | 24.90 / 13.40 / 10.82 | 16.71 / −1.28 / 22.87 |
| **扣除共同骨干的最终双候选** | **25.17 / 15.25 / 8.01** | **18.43 / 0.95 / 9.43** |

物理增益扰动同步改变电阻差和动态响应，保留无量纲归一化稳态响应。该方法降低固定池最低阶段的损失，却加大了历史回落。按分类间隔决定是否引入额外证据也经过验证，固定池平均收益为 15.28%。将额外证据上限从 4 调为 log(19) 后增长流均值仍为 25.17%，回落轻微升至 8.35 点。保留扣除共有证据的设计有同机制消融依据。

## 跨仪器测试与置信度

使用两种补充仪器各自的原生表示重新估计曲线与判别器。跨日电子鼻以前 8 个采集日拟合，在随后的 4 日选择头与温度，随后用前 12 日共 215 条记录重拟合，后 24 日的 409 条用于测试。DS-PS 使用三种气体 20–120 ppm 的独立重复暴露，前 4 次重复拟合、第 5、6 次选型，前 6 次共 108 条重拟合，其余 72 条留出。四个候选温度 .5、1、2、4 按内层负对数似然选择。温度只用于独立审查置信度。ECE10 按等宽置信度十档统计。[一年电子鼻数据](https://zenodo.org/records/15681119) · [DS-PS 数据](https://zenodo.org/records/19557093) · [Du 等，2026，漂移电子鼻的置信校准](https://doi.org/10.1002/cem.70148) · [scikit-learn 概率校准文档](https://scikit-learn.org/stable/modules/calibration.html)

| 外部测试 | 内层选择 V2 → V3 | 留出 Macro-F1 | 原始 ECE10 | 校准后 ECE10 | 校准后 NLL |
|---|---|---:|---:|---:|---:|
| 一年电子鼻 | 旧曲线 → tail | .5664 → .5334 | .3625 → .3484 | .2867 → .2392 | 1.6962 → 1.0901 |
| DS-PS | 旧判别 → independent | .4980 → .5077 | .2979 → .2867 | .0766 → .1158 | .9150 → .9147 |

跨日数据的 4,000 次按天配对重抽样得到 V3 减 V2 的 F1 差值 95% 百分位区间 [−.0769,+.0130]。其中独立投票头的测试 F1 为 .5955，高于所选 tail，但前序 4 日的选型倾向另一头。这保留了发布后分布变化可能让已选分支失效的实证。DS-PS 的类别区分略有改善，ECE10 的变化同时表明在新设备部署时要重新验证置信阈值。

## 资源与复现

在同一逻辑 CPU 上交替两版，每种设置重复三次，取中位数。增长顺序 0 的十轮 CPU 由 .646 秒降至 .591 秒，候选检查点合计由 2.129 MB 降至 1.798 MB，单条含 JSON 预测由 311 增至 399 微秒。固定顺序 0 的 CPU 由 .794 秒降至 .723 秒，候选合计由 2.761 MB 降至 2.280 MB，单条预测由 309 增至 414 微秒。实际工况中，预测延迟也取决于最终部署的头。float64 与紧凑 float32 归档逐轮对比，十个开发任务的部署选择和四项质量指标完全一致。V2 检查点在 V3 下的 1,244 条公开分数与原版最大差为 0。

在企业赛 V3 源码目录使用 ai-plus 环境并设置 OPENBLAS_NUM_THREADS=1 和 OMP_NUM_THREADS=1。运行 python -B gas_v3_study.py v2 与 frozen 重放十种开发设置，run 入口只遍历 0–4。数值结果在企业赛/work/v3/gas 对应目录。代表消融为 augment、pool、radial、range、heavy、combined 和 independent。full-v2、full-v3 验证完整公开首轮，cost 以单 CPU 复测，cross-day 评估跨日材料。读取 DS-PS 的 scipy.io 时，沿用服务器 /usr/bin/python3 -B gas_v3_study.py ds-ps。V3 镜像只持有运行模型代码和依赖。涉及外部仪器的评估使用各自原生特征与原生训练样本，未装入赛事镜像。
