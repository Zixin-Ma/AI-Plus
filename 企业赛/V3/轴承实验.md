# 企业赛 V3 轴承剩余寿命实验

## 改动针对什么误差

公开 B 验证含三台轴承。Bearing3_4 占 1515/1679 行。按真实寿命由短到长划成四段，真实均值为 189、568、947、1325 分钟，官方静态模型预测约 486、379、230、221 分钟。V2 原始头大致给出 658、705、662、628 分钟。整体水平得到修正，生命周期方向仍很弱。另两台轴承仅有 122、42 行，寿命短，增加全局偏移会进一步高估它们。按设备检查两轴频带能量后，选择由工况决定方向和力度的条件修正，并在高冲击或工况含糊时限制寿命外推。

## 模型与可用信息

运行端每次接收一行 34 维振动特征。两轴主频分别与三个已知工况的轴频、外圈、内圈及滚动体倍频匹配，得到三个软权重。工况为 35 Hz/12 kN、37.5 Hz/11 kN、40 Hz/10 kN。只有在候选转速与载荷关系符合这组实验设定时，才有依据把较长的寿命尺度分配给较高转速的工况。工况权重由频率相容性计算，不能直接当作标定过的分类概率。

新头的两个输入量均可在单次观测中得到。低频量是两轴 0–2 kHz 能量的对数均值，高频量是两轴 6–12 kHz 能量的对数均值。仅用本轮发布的训练对，在每个软工况中估计低频量的 13 个加权分位点、剩余寿命的加权中位数和下四分位数。用低频量的生存秩乘以两倍中位寿命，再按工况权重求和。“两倍中位数”对应均匀采样生命周期的尺度近似，并非真实设备总寿命标签。

- 寿命标签末端覆盖不足时，用最长寿命工况权重的平方控制分位估计，用最短寿命工况权重的平方对明显偏高预测有限下调。模糊的机械阶次对预测影响较小。
- 当至少 5% 的训练标签落入该批第 90 百分位寿命的最末 2%，开放较强的短寿命收缩。骨干预测已经偏长时限制向下修正。高频量从训练第 20 到第 75 百分位上升时，额外修正从全量线性降至零。出现强冲击时由此前经过验证的 V2 专家承担预测。
- 随产物保存曲线、工况寿命分位和幅值边界。FEMTO/KAIST 的标签、设备编号、样本顺序和未来观测均未进入部署头。两平台数据用于检验可迁移性。各经验分界由开发实验选择。

方法参考了 Yao 等按退化阶段组织多域健康指标与百分位归一化的研究，以及 Yang 等在工况漂移下分条件检验可靠性的方法。本文的单行经验曲线用官方已供应的频带特征实现。两项研究的原始数据、模型和成绩没有参与本项目的计分。[Yao 等，Machines 2026](https://doi.org/10.3390/machines14101119)；[Yang 等，2026 预印本](https://arxiv.org/abs/2607.08273)；[作者公开实现](https://github.com/nbbllxx0/Empirical-Calibration-and-Conditional-Reliability-Diagnostics)；[XJTU-SY 数据作者仓库](https://github.com/WangBiaoXJTU/xjtu-sy-bearing-datasets)

## 五组开发流

每种设置在 split 0 至 4 上各回放十轮。与 V2 头共享模型起点、样本、控制器与确定性评审。逐批流从 55% 训练行逐轮增长到全量，固定训练池每轮均持有官方起点和全训练集，两者都会轮换验证阶段。fresh 在同一阶段每次重访时更换选择样本。验证块与审计块分开。平均收益及最差轮收益以同一审计阶段对比静态模型的相对 RMSE 降幅计。回撤是单条流内曾见阶段相对其历史最优的最大下降，延迟是切换阶段后指标为负的连续轮数。表内四项都取五条流的平均值。本表隔离了轴承头，关闭共用控制器的附加静态端点和上下文复用。

| 设置 | 头 | 平均收益 | 各流最差轮收益均值 | 回撤 | 恢复延迟 |
|---|---|---:|---:|---:|---:|
| 逐批训练流 | V2 | 3.42% | −5.07% | 0.174 | 0.440 |
| 逐批训练流 | V3 | 4.18% | −3.17% | 0.144 | 0.190 |
| 固定训练池轮换阶段 | V2 | 24.77% | −4.32% | 0.514 | 0.300 |
| 固定训练池轮换阶段 | V3 | 31.81% | +2.53% | 0.476 | 0.075 |
| 重访更换选择样本 | V2 | 1.33% | −20.07% | 0.268 | 0.430 |
| 重访更换选择样本 | V3 | 3.08% | −15.33% | 0.216 | 0.295 |

固定训练池中 V3 的五个最差轮分别为 +14.11%、+7.83%、+3.40%、−7.38%、−5.31%。逐批流在 split 0、2 的最差轮转正，split 3 的最差轮仍为 −11.04%。fresh 的全局最差从 −62.11% 改善到 −36.58%。这些数字只说明公开回放的阶段表现。

## 替代路线和选择依据

| 路线 | 逐批平均 / 最差 | 固定池平均 / 最差 | 观察 |
|---|---:|---:|---|
| V2 对照 | 3.42% / −5.07% | 24.77% / −4.32% | 在最长验证设备上几乎不给出生命阶段差异 |
| 低频寿命秩，固定 0.7 混合 | 2.57% / −3.7% | 14.6% / −1.3% | 九台训练轴承整机留出最差约 1242 分钟 |
| 阶次置信度平方与短工况收缩 | 4.18% / −3.17% | 19.5% / −3.2% | 适合末端样本不足，对固定池收益偏低 |
| 双向条件收缩，全程启用 | 5.6% / −12.3% | 33.7% / +5.5% | 最长留出设备误差升至约 1311 分钟 |
| 双路同时交给选择集 | 5.8% / −12.3% | 33.5% / +5.5% | 逐批流回撤上升至 0.299 |
| 依末端覆盖切换，取消高频保护 | 4.18% / −3.17% | 33.7% / +5.5% | 充分覆盖时仍可能在新设备上过度收缩 |
| V3，经过冲击保护的单头 | 4.18% / −3.17% | 31.81% / +2.53% | 长设备损失较小，训练标定多保存 425 字节 |

高频保护上端的分位取 0.45、0.60、0.75、0.90 时，完整公开单头 RMSE 分别为 441.12、439.64、437.80、436.40 分钟，对应的九台留出最坏设备为 1068.51、1069.33、1073.68、1216.22 分钟。最终取 0.75。在验证主指标再降低 1.4 分钟时，0.90 拿到的最坏设备误差额外增长了 142.54 分钟。纯工况寿命、仅高频或峰度、简单多指标平均、分位级别与软阶次锐化的初筛结果保存在 panel.json，所有阈值都属于开发选择。

XJTU 九台有七台改善。以设备配对重采样 4000 次，V3−V2 的宏均值差为 −28.11 分钟，百分位区间 [−64.64, −1.69]。FEMTO 六台仅一台改善，宏均值差为 −3.38 分钟，区间 [−12.32, +1.45]，收益集中于个别设备。KAIST 取连续 128 小时内的 129 个采集文件，每文件取最早连续有效的 8192 个双轴采样点，25.6 kHz，其他两列温度不使用。回归目标为距离末次记录的分钟数。模型仅在 XJTU 训练，未经目标设备寿命标定。两版的排序相关都低，跨台架绝对预测误差仍大。[KAIST 原始数据 V6](https://doi.org/10.17632/5hcdd3tdvb.6)

完整首轮复现同一匿名验证池同时承担候选选择与结果读出，因此单独列出。V3 裸头的历史寿命四分位最大恶化量除以目标标准差为 0.3173。将寿命下调一档后的全权重候选 RMSE 为 468.48，但记忆恶化量仍为 0.2315，高于 0.18 的上限。最终选择 0.65 混合，记忆恶化量 0.1505，通过守门。增加 0.85 插值权重并保持原阈值可将完整首轮 RMSE 降到 496.86。该消融保存在 interpolation.json，冻结版本继续使用原有权重格与记忆阈值。

## 成本与复现

单线程 CPU 单独测量拟合头和逐行预测，在 1679 行上重复七次取中位。当前运行 V2/V3 分别用 0.0558/0.0768 秒拟合，单行 69.5/96.7 微秒，头数组 5816/6241 字节。真实完整首轮两者均调用模拟决策端 2 次，候选 npz 合计 40465/42449 字节。测量含 NumPy 开销和当时主机负载，完整 Harness 的系统资源应以综合压测为准。冻结头在完整与截短标签集上分别与研究实现核对全部 1679 行，最大批量差低于 2.3×10⁻¹³，单行与批量差低于 1.1×10⁻¹²。部署源 SHA-256 为 `6f43d337853cb0f3e43f55ce8a12ac7ef4ea9b3e9749579102092f9be894ca64`。

在服务器仓库根目录使用现有 ai-plus Python。数据与结果目录为 `企业赛/work/v3/bearing`。下列命令可重建候选、折结果、门槛诊断、成本及五组公开流，执行均不调用付费模型。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
python -B 企业赛/V3/bearing_v3_study.py
python -B 企业赛/V3/bearing_v3_study.py protect
python -B 企业赛/V3/bearing_v3_study.py impact
python -B 企业赛/V3/bearing_v3_study.py check
python -B 企业赛/V3/bearing_v3_study.py diagnose
python -B 企业赛/V3/bearing_v3_study.py grid
python -B 企业赛/V3/bearing_v3_study.py sweep v2,impact-supported-0.75 drift,official,fresh 0,1,2,3,4
```

每组流的逐轮训练规模、选择与审计规模、阶段、累计恢复及采用状态保存在对应路线目录的 JSON。整机主对照为 impact/panel.json 的 v2 与 impact-full-0.75，在含完整末端的训练折上它与冻结路径等价。final.json 保存采用后的完整首轮、跨平台单轨测试、微基准和设备配对结果。
