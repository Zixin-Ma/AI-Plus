# 企业赛 V3 · 工业漂移下的候选选择与回退

本版本从服务器企业赛 V2 迭代。Harness 使用赛方宿主提供的 Qwen/Qwen3.8-27B，实际续训对象是赛方提供的气体、轴承、发动机工业模型。规划和裁决均使用温度 0；发布时只上传一个候选。训练保留原归一化、MLP 及 Adam 状态，向后兼容已有 V2 头。三项分支研究、外部实验细节与负结果分别见《气体实验》《轴承实验》《发动机实验》。

## 与 V2 对比

同一公开实验框架先逐项复现 V2 的 15 条既有十轮漂移流，再在开发安排上比较方法。新阶段顺序和审计规则见 `work/v3/protocol.json`；训练代码、回放脚本、三份起点和六份公开数据文件的 SHA-256 于预留复验前固定在 `work/v3/freeze.json`。三条新顺序与三项任务组合成九条复验流，每流十轮。每种设置各有 V2、V3 两份独立结果。

| 九条冻结流的设置 | 平均相对收益 V2 → V3 | 各流最差收益的均值 V2 → V3 | 平均历史最大回撤 V2 → V3 | 恢复轮数 V2 → V3 |
|---|---:|---:|---:|---:|
| 逐批扩大训练池 | 11.62% → 13.29% | −10.89% → −2.06% | 18.45 → 7.76 个百分点 | 0.236 → 0.181 |
| 回访时提供新的选型块 | 9.18% → 12.58% | −13.90% → −3.74% | 26.34 → 20.75 个百分点 | 0.236 → 0.167 |
| 上述新块，中选允许历史产物 | 9.38% → 13.30% | −13.89% → −2.80% | 30.43 → 24.28 个百分点 | 0.208 → 0.153 |
| 完整固定训练池、官方检查点 | 19.24% → 20.08% | −1.57% → +1.99% | 27.02 → 24.40 个百分点 | 0.111 → 0.042 |

主漂移流的平均收益在九条中七条改善。最大历史回撤在三条中缩小、五条中增大、一条持平，宏均回撤的改善主要来自轴承灾难性退步受到限制。单一最低收益由 −81.17% 变为 −21.08%。在顺序 7 的轴承第 10 轮，105 条审计记录的静态 RMSE 为 248.49 分钟，V2 为 450.18，V3 回到 248.49。气体识别的每流最差收益均值却从 +9.99% 降至 +5.11%，发动机从 +1.45% 降至 −1.31%。固定官方公开首轮实际采用的 Macro-F1 为 0.8171 → 0.8623，轴承 RMSE 为 488.71 → 507.83 分钟，发动机为 47.28 → 47.91 循环。三项首轮使用发布模型的真实回执，V3 为三份新裁决使用 306 Token，三个相同规划复用 V2 的真实回执。

阶段指标以相同静态模型的 Macro-F1 增长或 RMSE 下降为正。回撤为已见阶段相对历史最佳收益的最大下降，恢复轮数从切换起计至相对收益非负，在阶段结束时截尾。任务与顺序等权。十轮研究回放使用固定应答；额外的 measured 回放在通过保护的候选及重新测量的历史产物间按当前主指标选择。不同顺序共享公开样本，fresh 在同一流的重复访问间分离选型样本，审计侧始终独立；C 按整机隔离。以上属于公开实验，平台隐藏分另行评定。

## 有效机制与竞争路线

气体的两个候选分别对幅度超出训练范围的响应限幅并使用厚尾残差，以及扣除两路重复使用的共同骨干证据。轴承根据工况、冲击和训练寿命覆盖调节校正，限制来源不熟悉时的外推。其候选包含静态参考的端点，更新幅度同时考虑振动分组内三个连续区段的误差。发动机对于延长寿命超过骨干预估的部分进行单边收缩，保留缩短寿命的方向。设备整机和巡航研究中对称误差、两方向寿命误差与 NASA 代价分别报告。

A、C 在相近环境再次出现时，最多检索最近六轮的有界输入均值与离散程度。只有过去真实规划且获准部署的动作可用于复用，当前候选仍必须接受当前验证及本轮模型裁决。B 两种复用方式都做过试验，其恢复与最差收益的代价使正式版本继续使用独立规划。按工况复用参考了近期复发漂移研究，工程实现只保存概括输入分布的数值以及动作回执。[2026 年复发漂移研究预印本](https://arxiv.org/abs/2610.36585) · [IJCAI 2026 漂移证据与更新](https://ijcai.org/proceedings/2026/503) · [CapyMOA 的漂移流实现](https://capymoa.org/api/modules/capymoa.stream.drift.html)

## 操作与复现

服务器项目根目录的 `校赛/work` 提供公开 JSONL、起点、SDK、基础镜像和 NumPy wheel，准备方式见 `校赛/README.md`。原始补充数据来自 `Supp_Datasets`。实验中按数据集的原生通道、物理单位和整机/日期分割检验迁移。压缩证据、运行日志、回执及大文件均在忽略目录 `企业赛/work/v3`。生产 SDK 走宿主网关，封装时使用 Linux/amd64、Python 3.12、NumPy 2.2.6、普通 UID 65534 与单线程。图像和资料生成使用服务器 M2Gaze 环境与 FFmpeg。

以下为服务器 `企业赛/V3` 下的复现命令，使用 ai-plus 环境。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python -B test_loop.py
python -B test_release_controls.py
python -B test_v3_policy.py
python -B checkpoint_io_study.py
python -B controller_study.py B anchor 3 fresh
python -B benchmark.py B v3 7 --setting fresh --review measured --profile
python -B qualify.py dev
python -B qualify.py freeze
python -B qualify.py confirm
python -B qualify.py summary
for k in A B C; do python -B resource_bench.py "$k"; done
python -B build_image.py
python -B verify_image.py
/root/miniconda3/envs/M2Gaze/bin/python -B release.py
```

已发布复验的 `protocol.json` 和 `freeze.json` 在证据包中。批量复现时先将它们放在 `企业赛/work/v3`，保证核对的是同一套数据和代码。上面的单条 benchmark 命令可独立执行。各研究脚本默认使用开放数据和本机 CPU。额外执行 `public_smoke.py A`、`B`、`C` 时，仅精确匹配的请求会使用缓存，新的网关请求会计费。

应用从 `harness.tar` 加载镜像 `bjtu-rsi:enterprise-v3`，由宿主调用 `describe`、`train`、`predict`。预测每收到一行输入即输出六类概率或非负寿命。上线按发布清单验证 SHA-256；真实运行中仅可选择授权的父产物、候选或重新测量过的可见历史产物。告警场景应分别审查弱势气体的漏报、轴承高冲击区的寿命误差及发动机寿命高估；设备维护仍由现场规程和检修人员决定。观察到回撤或输入失真时，可按已记录的镜像与产物 ID 恢复上一个获准版本。
