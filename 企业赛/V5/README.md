# 企业赛 V5 · 漂移下的气体识别和剩余寿命预测

V4 平台试运行三项均完成十轮。最终隐藏样本的 A Macro-F1 为 0.886405，B RMSE 为 331.534236 分钟，C RMSE 为 53.622878 循环，C NASA 非对称代价为 50,252,214,789.07。C 最终使用第 2 轮模型，第 3 至 10 轮候选的公开验证 RMSE 均高于父模型。该回执提供隐藏集最终指标和 19,197 个 Token 的用量，没有提供五个官方分项分数。V5 以这次观测确定实验优先级。

## 实验设计

在相同的训练释放、静态起点、选型样本和审计样本上分别执行 V4 和 V5，每个版本单独启动解释器。每轮先用可见数据部署，随后在四个隔离阶段核算预测。A 测量相对静态起点的 Macro-F1 增幅，B、C 测量 RMSE 相对降幅。流内十轮最低相对收益表征低谷，另报告历史最大回撤、切换后恢复到非负收益的延迟、单核耗时、SDK 单行端到端延迟、产物字节和控制调用。NASA 惩罚随低估与高估分别按 13、10 循环的尺度指数增长。流回放统计每行代价再按轮、流等权，整机和固定验证池另列求和指标。

开发顺序 0–10 用于选型。根据 11–13 号顺序另组确认集，事先登记评测脚本，冻结生产代码和九个公开输入文件的摘要后才运行。A/B 在各组内留出连续块，C 的审计行按发动机整台隔离。确认与开发共用官方公开数据，跨日与新设备的证据另见分支报告。逐批增长、按回访更换选型样本、回访时实测选择许可产物、完整官方起点、模拟 V4 的平台节奏共五套协议。最后一种仅沿用 V4 三十个公开训练/选型样本数的比例与已记录的动作。样本、阶段审计和实际部署由回放独立生成。控制调用在配对回放中采用相同确定性宿主，公开首轮另核验真实 Qwen 回执。

## 冻结后的结果

共 192 对十轮流、3,840 个逐轮记录，其中 45 对是预留的确认流。独立核算的最大浮点差为 1.12×10⁻¹⁶。轴承全部 640 对回合的部署选择与四阶段审计指标都一致。下表每格依次列 V4、V5。百分数为相对各自配对的静态基线收益，回撤单位为百分点。

| 确认协议（三任务、三顺序等权） | 平均收益 ↑ | 各流最低收益的均值 ↑ | 最大历史回撤均值 ↓ | 恢复轮数 ↓ |
|---|---:|---:|---:|---:|
| 逐批扩大训练池 | 14.54% → 15.49% | -1.53% → -0.63% | 10.70 → 13.32 | 0.181 → 0.105 |
| 回访更换选型样本 | 13.63% → 13.88% | -1.12% → -0.21% | 16.80 → 18.27 | 0.141 → 0.095 |
| 回访换样本，实测选择许可产物 | 14.95% → 14.47% | -1.29% → -0.38% | 16.60 → 20.45 | 0.157 → 0.095 |
| 官方起点与完整训练池 | 22.48% → 22.54% | 1.76% → 1.94% | 13.07 → 12.71 | 0.075 → 0.075 |
| V4 平台节奏公开模拟 | 20.31% → 20.36% | 5.07% → 4.09% | 5.77 → 4.59 | 0.032 → 0.032 |

C 在五套确认协议中的各流最低收益均值都提高，按每轮每行计算的 NASA 代价均下降。平台节奏模拟中 C 的低谷从 +3.18% 到 +3.71%，NASA 从 10,430.8 到 8,347.8。该协议的 A 低谷从 +5.91% 降至 +2.42%。在逐批增长中，A 低谷从 −0.87% 升至 +1.02%，但最大历史回撤均值从 14.08 增至 22.04 个百分点。回访实测择优时，三任务平均收益也略降。完整云端隐藏流和五项计分仍需另行运行 V5 才能得到。

实际部署的 C 任务头记住了其拟合时训练集的指纹。若后来一轮新候选被拒，控制器仍能判断父任务头是否见过当前数据。在固定最终专家的五条开发节奏流上，启用指纹使最低均值从 1.612% 升至 1.868%，最大回撤从 2.316 降至 1.981 个百分点，每行 NASA 均值从 41,754 增至 42,342。另七条开发流逐项保持相同。携带旧任务头、拒绝后衰减重试、尾部代价排序等路线分别保存逐轮对照。

公开首轮按请求摘要命中五个旧 Qwen 回执，C 部署复核新增一次调用，用量 102 Token。A Macro-F1 为 0.889048，B RMSE 为 507.834500 分钟，两者与 V4 相同；C RMSE 从 47.717531 降至 47.482635 循环。该首轮走实际训练和复核入口。SDK 镜像另用训练、上传、宿主应答、父模型回退及流式预测检查三任务各三轮。

## 模型、数据和工程依据

- **A 气体。** 限制动力学证据与原始传感器子空间证据分歧时的修正幅度，保留旧检查点的预测路径。对照原型密度、概率 PCA、固定混合等路线。补充验证包括一年电子鼻、DS-PS，以及 UCI 362 家用设备的日期留出。数据按仪器独立适配，最终生产模型只读比赛规定的可见特征。详见《气体实验.md》。[有限标签下的电子鼻漂移研究](https://ieeexplore.ieee.org/abstract/document/11763722) · [UCI 家用气体阵列](https://archive.ics.uci.edu/dataset/362/gas+sensors+for+home+activity+monitoring)
- **B 轴承。** 在原有 5% 末端支持门槛之外，仅当至少 12 个末端观测、至少 2.5% 末端比例及三种不同的零寿命双轴频带指纹同时成立，才启用成熟退化修正。指纹是信号证据，不能等同于真实设备 ID。七条路线用 XJTU、FEMTO、KAIST 及公开回放比较。详见《轴承实验.md》。[跨工况的校准研究](https://arxiv.org/abs/2607.08273) · [阶段化健康指标](https://doi.org/10.3390/machines14101119)
- **C 发动机。** 训练时计入部署允许的寿命修正幅度，用较浅的残差头和寿命序分类辅助目标建模。稳定阶段在本轮训练集中只用任务头没有抽中拟合的行校准序分类输出，同时约束高估和低估两侧的 NASA 尾部成本，校准量限于 ±10 循环。含 NASA 双尾、完全整机留出、N-CMAPSS DS02 及 CruiseBench 巡航子集对照。详见《发动机实验.md》。[CruiseBench 开源基准](https://github.com/NostalgiaJohn/CruiseBench)
- **资源。** 控制记录把原有三位小数的上下文保存为等价整数，恢复时兼容旧字段。固定静态参考直接继承，发动机低基数工况使用直方图求频数。镜像在构建时生成与源内容哈希绑定的 CPython 缓存。缓存对照用相同源码、依赖和产物，逐次校验预测。[PEP 552](https://peps.python.org/pep-0552/)

## 真实 SDK 的冷启动与单条预测

以下取五次交替测量的中位，两个版本各用自己公开首轮的产物。热延迟包含 JSON 管道往返、预测和序列化。另以相同 V4 检查点在两版运行时上逐条校验输出，完整分位数见 sdk-latency.json。服务器负载与评测机可能不同。

| 任务 | 热 p50，微秒 V4 → V5 | 热 p95，微秒 V4 → V5 | V5 相同镜像有无字节码的首包，毫秒（无 → 有） |
|---|---:|---:|---:|
| A | 635.69 → 668.77 | 859.03 → 919.52 | 986.0 → 623.5 |
| B | 167.92 → 163.66 | 299.37 → 225.42 | 955.2 → 611.7 |
| C | 78.61 → 113.38 | 117.79 → 159.38 | 937.7 → 592.3 |

同 V5 的冷启动对照每任务七次、交替顺序，逐行输出相同，缓存增加 4,505,600 字节。降低了启动成本，A、C 的已启动进程单条延迟仍高于 V4。工况分组的单核 CPU 从 161.65 降至 17.65 毫秒，30 条历史上下文等价编码从 18,583 降至 12,736 字节。五套确认协议共模拟 708 → 710 次控制调用。以上字节、调用次数与平台实际 Token 结算分别统计。

## 复现

在项目 ai-plus Python 3.12 环境进入本目录，运行下列命令。校赛阶段的公开投影、官方初始检查点、SDK 1.0.4、官方镜像基底和 NumPy 2.2.6 wheel 沿用同仓服务器目录。准备新环境时，将公开证据包根目录的 `protocol.json` 放在 `../work/v5/`，初次重跑时由 freeze 产生代码与公开输入清单，可与发布的 freeze.json 核对。每次实验前先阅读对应分支文档中的数据版本、切分和脚本入参。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 BASELINE_CPU_THREADS=1
python -B test_loop.py
```

`public_smoke.py A|B|C` 运行完整公开首轮，先校验已有模型回执的完整请求摘要，只在缺少完全匹配的回执时请求 PyTRIO。平台镜像在宿主提供的数据和候选路径上读写，预测阶段单条流式运行。宿主允许历史回滚时只能从获准的产物中选择。发行脚本 `release.py` 使用服务器 M2Gaze Python 的 PyMuPDF 和中文字体生成技术报告、源码包和公开证据包，校验 ZIP 的内容与体积并写入 SHA256SUMS。大件和实验输出位于服务器 `企业赛/work/v5` 的忽略目录。
