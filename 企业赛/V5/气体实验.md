# A 气体识别 · 用两种传感器证据的一致性控制漂移修正

企业 V4 的薄弱环节出现在每次重访工况都换一批公开选型样本时。开发顺序 5 的第 8 轮采纳了权重为 1 的 tail 头，当前阶段的审计收益跌到静态模型之下。V5 调整了这个头的两项证据如何相加。在 11 条换样本开发流中，各流最低阶段收益的均值从 5.72% 提高到 11.98%，全部流中的单一最低点从 −5.31% 提高到 0。

## 原理与部署

同一条气体阵列观测可以从两个角度判断。第一项估计当前响应与各类气体在相同稳态幅度下的动力学曲线之间的距离。第二项估计原始 128 维对数响应偏离各类低秩子空间的程度。近期电子鼻研究将分类器置信度、重构质量与潜在空间密度联合用于判断漂移后的样本是否可靠。我们比较了重构、密度、概率模型和证据一致性等路线。V5 使用源域训练得到的两个分支为同一条输入打分，无需额外采集目标工况标签或其他待测行。[2026 年有限标注漂移研究](https://ieeexplore.ieee.org/abstract/document/11763722) · [UCI 传感器响应分量的定义](https://archive.ics.uci.edu/dataset/224/gas+sensor+array+drift+dataset)

设动力学和原始子空间在各类别上的对数证据分别为 K、R。两向量各自减去类别均值后，计算余弦一致性 c，分母下限为 10⁻⁸。最终分类分数为

`log p(MLP) + [0.70 + 0.30 × max(0,c)] × K + R`。

中心化消除对全部类别相同的常数项。当两个来源对哪类气体更有可能意见一致时，动力学票保持接近原权重。当二者方向相反或某一来源没有区分力时，动力学票减少三成，原始响应与骨干仍可独立区分类别。新模型只多存一个标量。另一候选 independent 继续使用 V4 的稳态归一化、最多六个原型/类的核岭修正和原有公开面板选型。

## 十轮公开流

每条表项均为 0–10 共 11 个开发顺序等权。阶段收益按当前阶段相对自身静态起点的 Macro-F1 改善率计算。先对每条十轮流取最低收益或历史最大回落，再在流间取均值。恢复延迟以切换后重新获得非负收益所需轮数衡量，阶段末截尾。重复使用公开投影与每次重访都换投影的设置单列，验证行和审计行在每条流内互斥。表内均为企业 V4 → 企业 V5。

| 公开设置 | 平均收益 | 最低阶段的均值 | 最大历史回落均值 | 恢复轮数 |
|---|---:|---:|---:|---:|
| 增长训练池，重访时换选型行 | 21.969% → 23.523% | 5.721% → 11.983% | 29.464 → 15.623 点 | .045 → 0 |
| 同上，裁决选取准许的最高实测值 | 22.952% → 23.741% | 7.930% → 12.354% | 30.944 → 15.623 点 | .045 → 0 |
| 增长训练池，重访时复用选型行 | 23.318% → 24.339% | 10.470% → 13.056% | 11.599 → 9.448 点 | 0 → 0 |
| 固定官方起点与训练池 | 22.228% → 22.228% | 9.388% → 9.388% | 0 → 0 点 | .045 → .045 |

按固定回复裁决的换样本流中，顺序 5 的最低从 −5.31% 升至 20.3%，历史回落由 49.7 点降至 0。顺序 7 的历史回落却由 26.7 增至 33.7 点，顺序 10 的最低由 12.4% 降至 11.7%。因此这项改动改善了开发集平均低谷，个别投影仍会触发次优部署。44 个 V5 技术原型回放与采用冻结生产代码的重复执行使用同一批输入与回复。分项试验只使用 0–10，不包含全局后续顺序。

在官方 1,244 条完整公开验证行上，真实训练与候选读取入口从父模型 .71403 起步，使用离线 refit/half 规划。两版均采用权重 .35 的 independent，Macro-F1 均为 .88905，最低类别召回均为 .78659。

## 比较过的路线

在五个开发顺序 0、3、5、6、9 上先比较机制，再把有希望的方案扩展到全部 11 个开发顺序。五流与十一流只在各自范围内比较，未用终末外部样本挑选参数。

| 路线，五条换样本流 | 平均收益 % | 最低均值 % | 历史回落点 |

| V4 | 22.63 | 7.15 | 32.20 |
| 原始信号按类内噪声估计四维概率 PCA 子空间 | 23.14 | 10.58 | 21.57 |
| 沿幅度拟合类内轨迹和子空间 | 21.57 | 11.01 | 20.95 |

概率 PCA 在五条流上表现良好，扩展到全部 11 条换样本流后平均/最低均值为 20.83%/4.41%，低于 V4 的 21.97%/5.72%。按原型密度衰减 independent 的试验还使既有跨日窗口的选型改为旧曲线，Macro-F1 跌回 .5334。概率混合、密度调权和直接加物理票都保留了独立的逐流记录。概率 PCA 的对照参考开源实现对截断特征值和残差噪声的处理，生产部署只使用 NumPy。[scikit-learn 的 PCA 与 noise_variance_](https://scikit-learn.org/stable/modules/generated/sklearn.decomposition.PCA.html)

**浓度外推。** 先在 20–80 ppm 的每类前六次重复拟合，用第七、八次选型，再以这 96 条公开测量重拟合。最后在 100、120 ppm 的第九、十次重复上测试，只有 12 条，两个版本的共同低分反映超训练浓度下的风险。这一联合划分在模型选择前登记。组成该留出的 DS-PS 原始数据曾用于既有重复验证，应按新的划分解释。

**独立设备。** UCI 362 原始归档含 8 个金属氧化物传感器在家庭环境中的时间序列，三类为环境背景、香蕉与酒。以每次完整暴露为一个样本。用暴露前最多 15 分钟记录估计基线，在暴露期间提取稳态变化和 2、10、45 秒差分的上升/下降分位。设备响应、样本单位和气体类别均区别于赛事输入。100 条元数据中记录 95 没有对应的原始序列，实际配对 99 条，三类分别为 30、33、36 条。先锁定 59 个采集日期的 55%/75% 边界，前 47 条初训，中间 27 条选型，全 74 条重拟合，最后 25 条测试，两版均选 tail。下载物和中间证据保存在忽略目录。该测试要求一次暴露已结束，不能用于估计实时早期报警准确率。[UCI 数据、样本协议与原始归档](https://doi.org/10.24432/C5BS4F)

## 单条成本与复现

同一逻辑 CPU 上交替 V4、V5 各三次，取中位数。顺序 0 的增长、换选型样本、固定起点三种设置，含 JSON 单条预测分别为 493→536、499→527、548→508 微秒。十轮训练 CPU 分别为 1.026→1.029、1.006→.974、1.282→1.287 秒。对应十轮候选检查点为 1.759→1.760、1.835→1.841、2.485→2.485 MB。新方法着重改善弱阶段，增长池和换样本的单条计时略长。既有 V4 检查点在 V5 上有相同分数。对 1,244 条公开输入及 13 条压力输入测试两个新头和两个旧头，向量与单行分数最大差 1.64×10⁻¹³，分类结果完全一致。

从企业赛 V5 目录设置 OPENBLAS_NUM_THREADS=1 与 OMP_NUM_THREADS=1，以服务器 ai-plus Python 执行 python -B gas_v5_study.py v4 --full、angular --full、frozen --full，获得分别对应 V4、技术原型和生产 V5 的四种公开回放。full-v4 与 full-v5 检查完整公开首轮，single 验证单行等价性，cost 测量三次交替运行。cross-day:angular、home:angular、ds-ps:angular、cross-concentration:angular 对应表内外部协议。读取 DS-PS 的 MATLAB 数据使用 /usr/bin/python3。UCI 362 归档放入企业赛/work/v5/gas/home.zip，代码在读取前验证 SHA-256。全部证据位于企业赛/work/v5/gas。正式生产散列与外部切分的事前记录见 freeze.json、home-plan.json 和 external-plan.json。
