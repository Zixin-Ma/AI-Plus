# 轴承剩余寿命的公开漂移与跨设备实验

企业赛 V1 的完整校正头在 1,679 条公开验证行上得到 475.09 分钟 RMSE，但首轮部署后的误差为 644.09 分钟。从高寿命训练样本可以定位这个差距。按真实寿命分成四等份，最高寿命组的父模型误差为 284 分钟，套用完整校正头后达到 851 分钟，平均偏差从 −143 分钟增至 −823 分钟。V1 对这组回撤实施保护，最终只接受 0.15 权重。企业赛 V2 使完整校正头先保护这部分已有能力，使用相同首轮学步和首轮安全门槛后可以采用 1.0 权重，公开首轮部署误差降至 **488.71 分钟**。独立宿主替身重读落盘候选计算了这个数字。模型规划和评审使用固定回复。

## 方法设计

两个振动方向的主频可能同时接近多种转速的谐波。V2 对 35、37.5、40 Hz 三种公示工况计算转轴、内圈、外圈和滚动体频率的一致性，将软工况概率用于训练集寿命平方根的正则最小二乘拟合。模型沿用 V1 随载荷下降的寿命排序与大振动时退出总体先验的设计。[DX 2025，轴承故障特征频率与几何](https://doi.org/10.4230/OASIcs.DX.2025.9)

长寿命区使用训练输入拟合至多八个质心及收缩对角方差。当前预测处于训练预测第 60 百分位以上、校正头准备下调寿命、信号又接近长寿命训练簇时，模型减少下调幅度。相似度由到最近簇的标准化平方距离确定。训练行的近失效覆盖度决定这个保护项及软工况估计的强度，避免只看到轨迹前段就建立成熟寿命先验。所有阈值和中心只读当轮训练对，预测只需当前振动特征。按输入离开训练支持域的程度调整回退权重，与 2026 年 TrustMix 提出的域偏离门控思路有关；这里针对实数寿命和单方向的过量下调实现了独立方案。[TrustMix，2026 年 11 月 4 日预印本](https://arxiv.org/abs/2611.07206)

## 模块筛选

九个 XJTU 整设备折均从其余八根轴承重建训练起点。FEMTO 将 6 根完整寿命训练轴承按 10 个文件一条采样，补入每根终点，共 761 个双通道波形，逐根留出并重新训练。表中所有数值均为分钟 RMSE，越低越好。“公开部署”是同一完整验证池上采用相同保护逻辑后的数字，“九设备平均”是按照每根设备等权的误差平均值。两套数据各自拟合，外部设备权重没有进入提交模型。[FEMTO 公开归档](https://data.phmsociety.org/nasa/)

| 校正方法 | 公开单头 | 公开部署 | 九设备平均 | 九设备最差 | FEMTO 平均 | FEMTO 最差 |
|---|---:|---:|---:|---:|---:|---:|
| 企业赛 V1 | 475.09 | 644.09 | 584.78 | 1,070.08 | 90.36 | 196.38 |
| 只用阶次寿命先验 | 498.46 | 649.31 | 604.26 | 1,248.61 | 87.55 | 185.61 |
| 全输入支持度混合 | 542.73 | 584.57 | 612.65 | 1,113.68 | 88.81 | 193.43 |
| 分预测区间的误差带 | 570.08 | 605.51 | 648.08 | 1,256.02 | 85.33 | 189.51 |
| 只换软工况估计 | 469.44 | 641.26 | **578.36** | **1,067.29** | 90.24 | 196.32 |
| 16 维随机特征及长寿命保护 | 479.37 | 557.29 | 588.67 | 1,130.01 | 92.24 | 186.25 |
| **V2 软工况估计与定向保护** | **469.44** | **488.71** | 594.91 | **1,067.29** | 91.13 | 188.08 |

V2 对 XJTU 最差轴承减少 2.79 分钟误差，九根轴承中三根改善，等权平均误差增加 10.13 分钟。以设备配对重采样 4,000 次，平均误差差的 95% 百分位区间为 [−28.29,+45.35] 分钟。FEMTO 最差设备改善 8.30 分钟，六根设备中两根改善，平均差为 +0.76 分钟，[−3.65,+6.04]。跨机型应用应先确认几何与载荷组合，且需向现场维护人员报告不同设备的误差；最高风险设备和设备等权平均可能指向不同方案。

## 跨轮保护和恢复

固定训练池轮换评估每轮使用同一批官方训练对，并轮换公开验证片段。新增训练行评估从各设备前 55% 的记录重建起点，之后逐轮释放后续训练对。两者都留出选型未使用的审计行。每个场景含 10 轮，下表覆盖开发划分 0、1、2。每行“平均提升”为三场共三十轮中相对各阶段静态起点的相对 RMSE 改善，“最差”为其中最小值，“回撤”为各场历史审计增益最大跌幅的三场均值，“恢复”为从阶段切换至当阶段增益非负的平均等待轮数，等待最多计入当前阶段长度。两类场景分别汇总。

| 场景与方案 | 平均提升 | 最差 | 回撤 | 恢复轮数 |
|---|---:|---:|---:|---:|
| 新增训练行，V1 | 4.52% | −4.91% | 21.51 个百分点 | 0.33 |
| 新增训练行，V2 基础候选 | 4.94% | −4.91% | 39.91 个百分点 | 0.27 |
| 新增训练行，V2 加新数据更新步长保护 | **5.22%** | −4.91% | **19.56 个百分点** | 0.40 |
| 固定官方训练池，V1 | 20.06% | −15.05% | **45.44 个百分点** | **0.07** |
| 固定官方训练池，V2 | **27.11%** | **−5.24%** | 52.25 个百分点 | 0.33 |

新增训练数据触发校正头续训或重拟合时，限制步长能防止影响延续至过去阶段。具体做法是在至多 768 条训练留存探针上按真实寿命分四组，计算新旧预测每组平均差的绝对值，取其最大值。训练内容改变且已有父模型头时，这个移动量超过静态目标标准差的 0.15 倍即拒绝更新。该门槛和原有的组内误差保护分别检查预测移动与标签误差。

对照比较了整体预测差的 RMS、绝对预测差的第 80 百分位、四分位分组平均移动，并试了 0.15、0.25、0.35 三种限制。固定训练池里强制所有轮都遵守四分位 0.15 门槛时，最差阶段跌至 −40.1%。只有验证分布改变时，对历史输出的强约束会妨碍修复当前阶段。新增训练行时采用同一限制，则使回撤从 39.91 降至 19.56 个百分点。把容差提高到 0.175 后，新数据场景平均增益进一步增至 5.72%，但回撤回升至 33.11 个百分点。择定 0.15 的依据是新增训练数据时的稳定性。正式平台评分和专家分由评委确定。

## 资源与复现

原有编码器的 64 维随机特征使用 NumPy PCG64。在训练和推断都运行同一镜像时，保存训练规模即可按同一随机数调用顺序重建投影矩阵及相位。已逐元素验证重建矩阵相等，并在清空进程缓存后对 889 条输入复核单行与批量预测，最大绝对差约为 9.1×10⁻¹³ 分钟。在完整首轮，B 辅助头的张量量从 19,336 减到 5,816 字节，减少 69.9%。预测器保留对显式存储旧版投影的读取能力。长寿命簇拟合增加 CPU 成本；多次单线程微测中 V1 约 18–20 毫秒，V2 约 39–44 毫秒，单行数十微秒。平台资源分还包括 SDK 交互、推理调用和实际调度。

以下命令在服务器企业赛 V2 目录执行，用项目 Python 单线程运行。原始结果在企业赛的 `work/v2/bearing/`，单头筛选在 `loo.json` 和 `external.json`，模拟部署及真实入口重读分别在 `guarded.json`、`deployed.json`。不同保护方案的逐轮结果位于相应的 `guard-*` 和 `transition-*` 子目录。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python -B bearing_v2_study.py
python -B bearing_v2_study.py --external
python -B bearing_v2_study.py --guard
python -B bearing_v2_study.py --deploy
python -B bearing_v2_study.py --memory 0.18 0.50
python -B bearing_v2_study.py --transition quartile 0.15
python -B bearing_v2_study.py --transition release-quartile 0.15
```
