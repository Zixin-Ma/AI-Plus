# 发动机寿命分支的开发与复验

企业赛 V2 的 C 分支在首轮和训练池扩大后的重拟合中，将隐层宽度从 48 增至 64，训练从 20 个 epoch 减至 12 个。归一化、父 MLP 续训、残差上限、健康区间两端的小幅修正和单次输入均沿用企业 V1。当相邻两轮可见训练行数相同且已存在父校正头时，恢复 48 单元、20 个 epoch。调度只读取当轮行数、上一轮记录及父检查点是否存在。浮点训练只在 CPU 执行，模型预测输入为当前循环的 21 个传感器和三项运行设置。

**对照契机。** 11 月发布的 C-MAPSS 工况归一化预印本比较了带工况及历史变量的匹配基线，报告了 RMSE 与 NASA 非对称分可能异向变化。我们分别记录二者，并按整机划分独立设备。RanPAC 的开源实现使用冻结特征及读出更新处理连续分类任务。我们据此测试保留旧回归特征并对线性读出向父权重做正则化的方案。另按权重平均思想测试训练末期参数平均，比较预计算开销、推理开销和最差阶段。三个方案的输出均经过相同裁决逻辑。[工况对照原文和附属复现包](https://arxiv.org/abs/2611.28759) · [RanPAC 原文](https://arxiv.org/abs/2307.02251) · [RanPAC 官方代码](https://github.com/McDonnell-Research-Lab/RanPAC) · [权重平均原文](https://arxiv.org/abs/1803.05407)

**开发集与选型。** 使用企业赛公开回放的 split 0、1、2。每台训练发动机按时间从最早 55% 的记录开始逐轮追加至 100%，MLP 起点也只用首批已释放样本重建。审计单位是未参与本轮选择的整台验证发动机。不同划分使用不同阶段顺序及整机审计集合，划分之间包含部分相同设备。每次回放使用确定性规划及评审回复，执行生产训练和实际保存的候选预测。分项均为本地代理，具体换算以平台规则为准。选择顺序以三种顺序中最低的阶段收益为先，同时比较平均收益、回撤、恢复和 CPU。

| 路线 | 三个划分各自的最差阶段增益，% | 十轮平均增益均值，% | 最大历史回撤的三划分均值，百分点 | 恢复延迟均值，轮 | 十轮 train 入口 CPU 均值，秒 |
|---|---|---:|---:|---:|---:|
| 原 48 单元，20 epoch | +2.53 / −4.96 / −4.77 | 16.82 | 6.74 | .40 | 14.88 |
| 冻结编码，正则更新读出 | −5.70 / −8.0 / −4.4 | 14.53 | 11.5 | .53 | 12.93 |
| 周期性重建编码，其余更新读出 | +2.5 / −7.9 / −4.4 | 16.07 | 6.1 | .40 | 14.75 |
| 读出续训后微调编码 5 epoch | +2.2 / −4.4 / −1.8 | 16.99 | 7.2 | .40 | 15.75 |
| 64 单元，18 epoch，512 批量 | +2.0 / −7.1 / −.3 | 17.53 | 8.0 | .40 | 16.29 |
| 64 单元，12 epoch，末四个 epoch 权重平均 | +1.3 / −6.3 / −1.5 | 17.90 | 7.8 | .27 | 14.32 |
| **新增样本分支，64 单元、12 epoch** | **+2.53 / −3.75 / −.89** | **17.67** | **6.83** | **.40** | **12.88** |

冻结方案将三个顺序中最低的阶段收益提高了 1.20 个百分点，平均收益增加 0.85 个百分点，十轮 train 入口累计 CPU 减少约 13%。split 0 的平均收益从 24.99% 变为 24.92%，最差增益的变化小于 0.01 个百分点；优势集中在另两种顺序。split 1 的历史回撤从 4.08 变为 5.89 个百分点，split 0 和 2 则下降。开发回放计时覆盖本地训练、分组验证、候选序列化和提交给宿主替身的阶段，未包括 CPU 计量体系中的平台流水线与网关等待。精确每轮数值见企业赛 `work/v2/engine/{路线}/drift-v2-C-{split}.json`。

**固定训练池的调度消融。** 初选短宽头后，用赛方提供的完整静态 MLP 和原公开训练池重复三种验证流顺序。原头→始终短宽头的三划分平均收益为 15.61%→14.29%，三个顺序中最低的阶段收益为 −2.37%→−4.69%，平均回撤 2.31→2.17 个百分点，平均恢复延迟均为 .27 轮。十轮 train 入口平均 CPU 从 18.16 降至 16.91 秒。固定训练池下短训练会损失精度。随后固定同一控制器，完整比较四种预先定义的调度，每种运行两个池状态和三个开发顺序，共 24 次回放。

| 第一次与后续重拟合安排 | 新增训练池平均/最低阶段，% | 固定训练池平均/最低阶段，% | 新增池历史回撤，百分点 | 新增池恢复延迟，轮 |
|---|---:|---:|---:|---:|
| 始终 48×20 | 16.820 / −4.956 | 15.610 / −2.373 | 6.739 | .400 |
| 始终 64×12 | 17.674 / −3.755 | 14.289 / −4.693 | 6.834 | .400 |
| 首轮 48×20，更新池 64×12，稳定后 48×20 | 16.770 / −3.755 | 15.610 / −2.373 | 7.715 | .533 |
| **冻结调度：首轮 64×12，更新池 64×12，稳定后 48×20** | **17.674 / −3.755** | **15.537 / −2.644** | **6.834** | **.400** |

固定池最终恢复延迟与原头均为 .267 轮，历史回撤分别为 2.322 和 2.310 个百分点。初始短头保留了新增池首轮收益，固定池首轮选中的模型仍会影响后续轮次，因此固定池相对原头保留小幅差距。同样行数也可能对应样本替换；行数相同是策略中的低成本代理，公开验证与父模型比较继续约束采纳。新增调度结果在 `work/v2/engine/schedule`。这些记录位于与开发实验相同的路线目录内，文件名前缀为 `official`。

**独立设备与外部测量。** 另外对模型头进行四次训练释放的直接对照，逐台按 55%、70%、85%、100% 释放。两版共用首批训练样本重新拟合的 MLP，不经过宿主选择器，以观察模型头自身的影响。内部数据的两折分别留出全部 unit 模 5 等于 1 或 2 的发动机，使用源子集与 unit 的组合标识机器。外部实验用 N-CMAPSS DS02 开发区的 4 台机器训练、2 台整机留出，采用原生测量变量和训练内运行设置分位。CruiseBench 掩码按同一机器及循环对齐。外部数据来自真实飞行工况驱动的仿真退化轨迹。两套外部材料共享样本来源。[N-CMAPSS 作者原文](https://doi.org/10.3390/data6010005) · [CruiseBench](https://github.com/NostalgiaJohn/CruiseBench)

C-MAPSS 整机折 1 的 NASA 总分从 32.41 亿升到 36.51 亿，折 2 从 141.19 亿降至 133.13 亿；DS02 从 22,419 降至 20,367。所有比较保留原始寿命单位，各数据集的总分由其样本规模和误差尾部共同影响。外部航段、工况和机队结构均会影响新场景的表现。三组冻结模型逐样本与批量输出的最大绝对差均小于 1e-12。

**复现。** 在服务器企业赛 `V2` 目录进入 ai-plus 环境并设置 `OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1`。运行 `python -B engine_v2_study.py cold 0` 与 `python -B engine_v2_study.py leanwide 0` 可做原头和冻结头的十轮对照。将 0 改为 1 或 2 检查其他开发顺序，在末尾添加 `official` 使用官方起点与固定训练池。其他代表路线名称为 `warm`、`periodic`、`tune5`、`large`、`swa`。运行 `python -B engine_v2_study.py check fold1`、`check fold2`、`check DS02` 可重复四次释放与标量对照。DS02 的原始抽样来自企业赛 V1 的 `engine_study.py extract`，中间数据从已忽略的服务器目录读取。复现冻结调度可用 `python -B engine_v2_study.py frozen 0`，比较首轮安排的路线为 `scheduledshort`、`scheduledlong`。实验未使用 PyTRIO 调用额度。
