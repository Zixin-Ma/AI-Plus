# A 气体分支的路线与边界

企业 V2 在每次重拟合时提出两个候选，均从同一个已续训的 MLP 出发。一个使用企业 V1 的核回归和子空间组合，另一个显式估计每种气体的动力学响应随阵列幅度变化的轨迹。当前公开验证面板联合比较分类性能和分组保持率，每轮提交一个候选。选择依据和实际采用的头写入训练记录。已保留解读 V1 头和单纯 MLP 的预测路径。

**条件轨迹。** 对每个样本，取 16 路稳态响应对数幅度的均值为观测量 (q)。训练集拟合 (q) 的尺度，截断到三个标准差以内。用岭回归为每种气体拟合 (q) 到 96 维动力学特征的二次函数。把六个类别的残差协方差等权平均，以 0.12 收缩后在 24 维空间度量残差；每类局部方差最大的四个方向适度折减惩罚。第二个距离取自 128 维对数响应的三维类内子空间，与前一距离及 MLP 的对数概率相加。单条预测只依赖自身读数。幅度可以反映多种因素，算法并未将它当作已知浓度或漂移标签。

拆分 0/1/2 用于开发。表中的阶段是固定公开审计片段，与官方隐藏阶段的组成可能不同。模拟恢复延迟对到阶段结束仍未恢复的事件按该段长度截尾。拆分 0 的第 7 轮在阶段 3 接受曲线头后，旧阶段 0 的审计 F1 从 0.9266 降到 0.7585。第 9 轮回到阶段 0 并接受原有架构的头，旧阶段 3 从 0.8665 降至 0.6896，低于该阶段静态起点的 0.7349。这解释了当轮指标向好而历史阶段最大回落上升的情形。

**为什么保留第二个候选。** 只用冻结的曲线头，在完整公开训练及验证首轮上 Macro-F1 为 0.5398，企业 V1 为 0.8277。在训练内按类别时序划为四折、从头重训的条件下，曲线头最低折为 0.9421，V1 为 0.9158。两种设置的次序相反。使用官方起点及完整训练池的三条十轮路径上，双候选的 12 次新模型采纳均选中 V1 头。三条路径复现 V1 的平均、最差、保持与恢复指标。另试加入以单一子空间为主的第三候选，固定池拆分 2 最差退至 −8.82%，故保留两条路线。只用幅度条件曲线、去除原始响应子空间时，逐轮释放拆分 0 的历史回落曾达到 0.4536。把完整 V1 分数以 0.5 权重和条件轨迹相加，在逐轮释放拆分 1 的最差仍为 −1.81%。资源记录与冻结拆分的结论以主报告为准。

**独立仪器与实际开销。** 一年漂移数据取前 12 日拟合，后 24 日测试。V1 与曲线头的 Macro-F1 分别为 0.6067 和 0.5664。按采集日配对重采样四千次，曲线减 V1 的 95% 百分位区间为 [−0.0853, 0.0022]。在前八日拟合、随后四日选型时，71 条可见样本更偏好曲线，随后 409 条样本上的 F1 为 0.5664。这说明旧选型窗口即使分出胜负，未来窗口仍可能变化。DS-PS 使用三种物质 20–120 ppm 的 180 次独立暴露，前六个重复训练、后四个重复测试。V1 和曲线头分别得 0.4980 和 0.4259。前四个重复拟合、第五至第六个重复选型时成功选回 V1。外部试验按原仪器的测量布局重训，原始补充数据和外部拟合的权重均未写入赛事镜像。[一年期电子鼻数据](https://zenodo.org/records/15681119) · [2026 年 DS-PS 发布](https://zenodo.org/records/19557093)

同一公开首轮，曲线头压缩后 55,339 字节，V1 头 145,704 字节。三条逐轮释放路径仅用曲线时，逐样本返回完整预测的 CPU 时间为 251–271 微秒，配对 V1 为 300–318 微秒。固定池的三条路径最终选择 V1 头，同一组运行中两路候选的 30 轮合计 CPU 由 2.12 秒升到 2.66 秒。资源收益取决于何时触发重拟合及最终采用哪一头，正式计量由平台给出。

**复验入口。** 从项目根目录设置 `OPENBLAS_NUM_THREADS=1` 和 `OMP_NUM_THREADS=1`，以 ai-plus 环境运行 `python -B 企业赛/V2/gas_v2_study.py public`、`cross-day`、`full`、`curve` 或 `union`。读取 DS-PS MATLAB 数据的命令为 `/usr/bin/python3 -B 企业赛/V2/gas_v2_study.py ds-ps`。双候选回放使用 `python -B 企业赛/V2/benchmark.py A v2 0 --profile`，可增加 `--setting official`。记录分别在 `企业赛/work/v2/gas` 和 `企业赛/work/v2/replay`。核心气体模块已经核对旧权重兼容和逐行、批量分数相符。
