# 企业赛 V2 · 漂移下的工业模型续训

本版本基于企业赛 V1。正式入口为 `contest_submission.py`，三项任务分别在 `gas.py`、`bearing.py`、`engine.py` 实现。产物位于服务器 `企业赛/work/v2/delivery`。比赛镜像使用 Linux/amd64、Python 3.12、NumPy 2.2.6、Harness SDK 1.0.4，单线程、普通用户运行。驱动规划和部署裁决的模型为宿主提供的 Qwen/Qwen3.8-27B；实际拟合的是赛方工业模型及其校正头。

## 实验结果与选型

先在三个既有公开阶段安排中复现企业 V1，再做分项和控制器消融。最终锁定运行模块和回放脚本的 SHA-256，记录在 `work/v2/freeze.json`，随后开启两条预留顺序。六条复验流按任务和顺序等权。阶段收益是相对相同静态起点的 Macro-F1 增长率或 RMSE 下降率。稳定性取已出现阶段相对其历史最高收益的最大回撤。切换后的恢复延迟是相对静态收益转为非负前的轮数，阶段结束时截尾。每流十轮，选型行与审计行在流内隔离，多个顺序共享公开数据来源。

| 六条冻结复验公开代理 | 企业 V1 | 企业 V2 |
|---|---:|---:|
| 当前阶段相对收益均值 | 8.78% | 13.31% |
| 每条流的最差阶段，再对六条流取均值 | −7.39% | −0.88% |
| 全部阶段的单一最低收益 | −12.76% | −12.49% |
| 历史最大回撤均值 | 14.04 个百分点 | 13.42 个百分点 |
| 切换后平均恢复延迟 | 0.375 轮 | 0.250 轮 |
| 规划和裁决调用次数 | 116 | 108 |
| 所有模型请求正文大小 | 77,767 字节 | 51,267 字节 |

A 在两组预留顺序的最差阶段收益均转正；其中一个顺序的历史最大回撤由 21.35 增至 34.99 个百分点。B 在一个预留顺序的平均阶段收益由 +1.13% 回落到 −0.54%，另一顺序的最低点为 −12.49%。C 的固定训练池收益仍略逊，某些预留顺序取得更小回撤。这些量来自公开代理。校赛 V2 的 16.769565/35 分属于之前的平台正式评测，企业 V2 隐藏成绩另由平台评定。

固定官方检查点、一次性放出完整训练池的九条公开流给出了另一组取舍。平均相对收益从 17.00% 提至 19.32%，每流最差阶段均值从 −2.04% 到 −1.86%；平均最大回撤从 21.25 增至 23.52 个百分点，恢复延迟从 0.156 增至 0.244 轮，主要代价来自轴承任务。

## 方法与应用

- A 对气体的响应幅度拟合二次动力学曲线，结合类内低秩距离。每次重拟合均与 V1 判别头在同一批公开选型样本上比较。两类外部电子鼻分别评估跨仪器输入布局与跨日变化，保留曲线法退化时的对照。
- B 在寿命尾部使用训练支持度和振动阶次的软权重。已有校正头且训练数据改变时，对四个寿命分位分别比较新旧预测的平均变化，控制上限为训练目标尺度的 0.15。固定训练池遇到不同验证环境时可完整更新。
- C 在首次或新增训练数据时选用 64 个单元、12 个 epoch 的校正头。在相同训练池持续出现且已有头时沿用 V1 的 48 个单元、20 个 epoch。训练数据的形状、值、顺序和标签纳入摘要。兼容旧记录时可用历史行数判断。
- 三项均从宿主授权的父产物恢复骨干、归一化参数和 Adam 状态。宿主模型规划实际训练动作；每轮只上传一个候选并请求一次真实部署裁决。验证比较涵盖当前主指标、最弱组和静态参考。回归另检验寿命分位的误差回撤。无效裁决或候选越过保护阈值时保留父产物；仅重新测量宿主列出的近期历史产物。
- 可用于气体仪表校准复核、轴承巡检和发动机检修排程。在设备验收中应按气体、工况、寿命阶段分别监控误报、漏报和寿命高估代价。发布保留原镜像摘要及检查点，必要时恢复两个版本对应的镜像与资产。

开发参考了对漂移证据分配更新强度的 IJCAI 2026 研究，以及 River 对选择性更新的实现。项目以每轮公开选型、训练释放变化与寿命分层约束落地；三份分项记录列出具体研究、开放数据及负结果。[IJCAI 2026](https://ijcai.org/proceedings/2026/503) · [River](https://riverml.xyz/dev/api/forest/ARFClassifier/)

## 复现与验收

以下命令在服务器 `企业赛/V2` 下执行。公开训练和验证数据、官方起点、SDK 和固定依赖沿用 `校赛/work`，准备说明见 `校赛/README.md`。外部原始文件来自项目根目录的 `Supp_Datasets`。训练入口只依赖镜像内运行组件。外部研究额外使用 SciPy、h5py 等工具，见三份分项文档。

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
python -B test_loop.py
python -B test_release_controls.py
for k in A B C; do
  for v in v1 v2; do
    for n in 0 1 2 3 4; do python -B benchmark.py "$k" "$v" "$n" --profile; done
    for n in 0 1 2; do python -B benchmark.py "$k" "$v" "$n" --setting official --profile; done
  done
  python -B resource_bench.py "$k"
done
python -B controller_study.py class04 0
python -B build_image.py
python -B verify_image.py
/root/miniconda3/envs/M2Gaze/bin/python -B release.py
```

`drift` 从每组首 55% 的公开训练样本重建相同起点，逐轮释放到 100%。`official` 固定官方起点并一次性提供完整公开训练池。A/B 用观测顺序的连续分段，C 按整机隔离选型与审计，按循环分段。Harness 看不到用于切分的设备标识。十轮配对回放使用固定模型应答，CPU 结果含候选序列化及复算。单条预测计时含 JSON 序列化。同一任务两个版本绑同一 CPU，交替测量三次取中位。

真实 27B 公开首轮使用 `public_smoke.py A`、`B`、`C`。相同请求复用凭据目录以外的响应回执，不同请求会使用平台额度。本版本保留规划器输出格式修正的两份原始回执；公开首轮离线选择及正式评测配额由不同流程管理。推理请求、访问令牌和账号配置均不随比赛镜像分发。

生产镜像标签 `bjtu-rsi:enterprise-v2`。宿主以 `describe`、`train`、`predict` 调用 SDK 入口；预测读一行 JSON，分类返回六类分数，回归返回非负寿命值。每个发布文件的 SHA-256 见成品清单。训练、清除和恢复相关动作均须使用当前宿主声明的路径及产物 ID。
