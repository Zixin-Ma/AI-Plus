# 企业赛 V8 轴承寿命预测

冻结实现位于 `bearing.py`，SHA-256 为 `d1ef9cc8173326c3979915b7c69d60bd618e5001158fbfe7996eea35c03df040`。V5 平台试运行的隐藏 RMSE 为 331.53 分钟，V7 为 417.54 分钟。V8 用这一公开的汇总差异确定改进目标，未使用隐藏样本或平台反馈调参。以下 V8 数值全部来自公开数据。

## 从设备偏差到分位校正

V7 倾向短寿命设备。相同训练发布下，V5 的全局低振动寿命先验为 756.7 分钟，V7 为 250.1 分钟。三个转速工况的先验分别从 199.8、894.5、1016.4 变为 66.3、86.4、1659.5。九个公开源设备的时长差异很大，按设备重估典型寿命有助于短寿命设备，放大了对目标设备构成的依赖。V7 在公开首轮使两台短设备 RMSE 从 310.07、418.11 降到 201.61、229.10，却使 1515 行长设备的 RMSE 从 522.71 升到 542.04。隐藏集只提供聚合结果，无法定位造成隐藏退化的具体设备。

V8 继承 V5 的寿命先验与频谱工况划分，依据公开训练轨迹估计可修正的两类偏差。

- 依序递减的剩余寿命和标签向上跳变用于识别训练轨迹。至少需要三段有效序列，每段至少十个观测、合计覆盖至少 85% 的数据。超过 14% 的相邻差值非负时沿用 V5。推理时每次只需当前振动特征。
- 至少三分之二的轨迹接近末端（末值最多为首段最大寿命的 10%，下限 1 分钟）时，计算每段 V5 预测的有符号平均残差。取这些设备均值的上四分位，限制在全体残差绝对值中位数以内，再修正残差模型的截距。这能限制短寿命设备占比变化时对长寿命区间的低估。完整轨迹占三分之二后，该修正减半。
- 完整轨迹须观测到实际的零寿命终点，并有非零寿命跨度。至少三段且占有效轨迹三分之二时，提取每台设备双轴低频能量对数均值的 2.5% 到 50% 分位。先按各自中位数居中，再按转速软归属与轨迹长度平方根加权。保持 V5 三组工况中位数，将中位以下的六个分位节点向组内新估计移动 75%。中位以上的高能量节点保留原坐标。这样可调整安静期振幅与寿命之间的曲线，并保留振动冲击区的原标定。
- 新系数与分位点直接存入已有专家头。无需保存设备 ID、原始波形或训练样本，当前检查点继续使用同一单条推理函数。

2026 年 Fusion-VHI / Diff-GPR 研究用设备级百分位归一化与退化阶段定位处理寿命非平稳性，支持对秩尺度与阶段条件分别验证。在本赛题的单记录接口中，V8 只从训练轨迹估计这些量，并用额外的高能量半边消融检验保留冲击区的选择。[论文](https://www.mdpi.com/2075-1702/14/10/1119)

跨工况不变性研究同时使用 XJTU 与 PHM2012 验证，开源 RUL Datasets 则按设备与工况组织 XJTU、FEMTO 数据。这里采用相近的整机留出原则，另用 KAIST 检验跨台架偏移。官方输入投影和 XJTU/FEMTO 原采样策略沿用前版，文献滚动预测结果未纳入赛事性能比较。[跨工况研究](https://journals.sagepub.com/doi/full/10.1177/16878132261476531) · [RUL Datasets](https://github.com/tilman151/rul-datasets)

## 首轮部署及完整寿命

运行生产训练入口，从官方起点使用全部 7032 行公开训练、1679 行公开验证，移除设备元数据，由同一 V8 控制器选模型再加载冻结权重评估。该数据参与本阶段路线选择。设备宏平均来自另一协议，每次完整留出一台。误差单位均为分钟。

| 公开端点 | V5 | V7 | V8 |
|---|---:|---:|---:|
| 首轮部署 RMSE | 507.83 | 519.01 | **460.38** |
| 首轮部署 MAE | 423.96 | 420.01 | **374.29** |
| 逐台等分四个寿命段后的最坏区间 RMSE | 838.59 | 879.60 | **783.22** |
| 第一、二、三工况设备 RMSE | 310.07 / 418.11 / 522.71 | 201.61 / 229.10 / 542.04 | **288.20 / 343.39 / 474.28** |
| 完整公开首轮裸专家 RMSE | 437.80 | 431.01 | 434.36 |
| XJTU 九台整机宏均 / 最坏 RMSE | 566.80 / 1073.68 | 531.23 / 1096.37 | 560.64 / 1079.03 |
| FEMTO 六台整机宏均 / 最坏 RMSE | 87.73 / 189.29 | 86.02 / 189.27 | 88.30 / 188.66 |
| KAIST 129 个小时观测零适配 RMSE | 3607.66 | 3653.84 | 3618.96 |

端到端的提升既来自曲线调整，也来自候选选择。公开部署中 V5 和 V7 的专家混合权重均为 0.65，V8 为 1.0。固定为裸专家时，V5 与 V8 仅相差 3.43 分钟，表中的 47.45 分钟差异包含守门选择。首轮三台的全设备 RMSE 均优于 V5；第一台自身最坏四分之一区间从 414.76 变为 419.54 分钟。FEMTO 均值及 KAIST 零适配稍差，XJTU 的单台最坏值也有回退。

## 阶段回放、开销和复现

同一冻结 V7 控制器下，以 V5、V7、冻结 V8 三个专家分别回放五种协议。每格汇总 10 个相同顺序，合计 150 条完整十轮轨迹。核对每轮的审计样本、阶段、静态模型与发布样本。

| 协议 | V5 阶段均值 / 最低 | V7 阶段均值 / 最低 | V8 阶段均值 / 最低 | V8 相对 V5 最低改善顺序数 |
|---|---:|---:|---:|---:|
| 发布表＋同域 | +0.0354 / -0.0795 | +0.0751 / +0.0023 | +0.0547 / -0.0494 | 10/10 |
| 发布表＋选模留出当前工况 | -0.0098 / -0.0957 | +0.0110 / -0.0945 | +0.0214 / -0.0671 | 10/10 |
| 阶段内更新选模样本 | +0.0193 / -0.0418 | +0.0278 / -0.0199 | +0.0194 / -0.0418 | 1/10 |
| 阶段漂移 | +0.0197 / -0.0238 | +0.0337 / -0.0100 | +0.0157 / -0.0334 | 0/10 |
| 官方静态起点＋逐阶段选择 | +0.2593 / +0.0189 | +0.2978 / +0.0198 | +0.3238 / +0.0308 | 3/10 |

阶段均值对各阶段等权；“最低”先在单条回放中取最小阶段均值，再跨顺序平均。10 个顺序重复使用相同公开设备。接近失败的截断轨迹与观测到确实终点的轨迹有不同证据强度；早期发布直接沿用 V5。

- 发布表＋同域最大遗忘降幅（越小越好）V5 / V7 / V8 = 0.2638 / 0.1567 / 0.3337，平均恢复延迟（轮）= 0.750 / 0.600 / 0.750。
- 发布表＋选模留出当前工况最大遗忘降幅（越小越好）V5 / V7 / V8 = 0.0575 / 0.1459 / 0.0491，平均恢复延迟（轮）= 0.900 / 1.200 / 0.900。
- 阶段内更新选模样本最大遗忘降幅（越小越好）V5 / V7 / V8 = 0.1380 / 0.2055 / 0.1393，平均恢复延迟（轮）= 0.313 / 0.216 / 0.313。
- 阶段漂移最大遗忘降幅（越小越好）V5 / V7 / V8 = 0.1500 / 0.2063 / 0.1516，平均恢复延迟（轮）= 0.232 / 0.257 / 0.291。
- 官方静态起点＋逐阶段选择最大遗忘降幅（越小越好）V5 / V7 / V8 = 0.5305 / 0.5785 / 0.5207，平均恢复延迟（轮）= 0.000 / 0.057 / 0.045。

在相同输入的标量与批量路径上，绝对误差不超过 1.4×10⁻¹² 分钟。完整训练发布与独立实验实现的最大预测差为 1.2×10⁻¹³ 分钟。打乱标签顺序、逐设备截半、加载旧 V5 权重时，新旧结果一致。九次交替测量各抽 800 条，V5 与 V8 的纯专家单样本耗时中位数分别为 46.17、43.95 μs，调用期间服务器同时在跑验证任务。模型结构及推理运算相同；此测量覆盖模型内核，评测平台端到端效率须另测。

实验脚本为 `bearing_v8_study.py`。在 AI+ 仓库根目录和项目 Python 环境运行，数值库设为单线程。下列入口复现生产、首轮与跨设备结果，将原始 JSON 写入 `企业赛/work/v8/bearing` 的指定子目录。

## 冻结后诊断：真实 Qwen 回放为何漏掉第一工况

三条回放均在第 1–3 轮批准权重 1.0 的专家；第 4 轮淘汰新候选并保留第 3 轮工件，所以这两轮审计收益相同。第 1–3 轮可见选择组最低收益在三个切分均依次为 +2.36%、+1.18%、+0.49%，三个切分的当前工况审计收益同期均为负。守门依据的分组是振动特征代理组，候选可见总体 RMSE 持续改善，代理组底线没有发出负值警报。V5 在第一工况同样出现负收益。201 与 207 的 V8 首轮已落后 V5，203 的 V8 首轮为 −20.93%，反而优于 V5 的 −32.11%，其退化集中在后续三轮。

### 首轮专家混合权重上限的独立开发对照

在开发切分 0、5、13 中固定官方起点、V8、训练发布和确定性计划/复核，比较原菜单与只在第一轮去掉权重 1.0 的菜单。其余轮次恢复原菜单，用每轮训练/选模/审计记录及静态 RMSE 核对配对关系。共六条十轮回放，所有操作在本地服务器上运行。

| 开发切分 | 冻结 V8 阶段均值→限权 | 冻结 V8 阶段最低→限权 |
|---|---:|---:|
| 0 | +9.15%→+7.94% | -14.01%→-17.63% |
| 5 | +15.26%→+14.21% | -2.68%→-5.84% |
| 13 | +7.68%→+6.45% | -20.46%→-24.17% |

三个开发切分的最低与平均收益均下降；第 2–10 轮的阶段审计收益逐项相同。读取真实首轮候选配置后可见，去掉权重 1.0 也改变了所选寿命偏移：三个切分从“专家权重 1.0、−105.35 分钟”一并变为“权重 0.65、偏移 0 分钟”。该项实验识别的是修改候选菜单的部署效果，不能把差异全部归因于线性混合本身。直接加首轮上限缺少实验支持。更值得单独验证的是，振动代理组上可接受的权重与偏移组合能否经受整台设备留出的检验。
