# V8 发动机寿命预测实验

V5 平台试运行和正式评测的最终隐藏 RMSE 为 52.884726 周期、MAE 为 37.455276 周期、NASA 为 250.931 亿。V7 试运行的对应结果是 53.205220、37.696688 和 250.589 亿，十轮使用的都是首轮工件。V8 因此同时考察首轮训练、后续更新被采用的次数，以及停留在同一工件时的终态误差。下列 V8 结果来自本地公开数据。

## 训练设计

- 接近故障的训练行已经发布时，相邻轮次得到的标签分布变化较小，但末个随机梯度迭代仍会受最后几个批次影响。V8 对此类新发布轮的后半程参数快照作等权平均。识别条件只使用当前已发布寿命标签。要求至少 512 行，至少 93% 相邻标签恰好递减一个周期，且至少八段连续轨迹各覆盖 16 行。对每段末行与首行寿命比值取中位数，位于 0.5% 至 16% 时启用。首轮完整轨迹也启用。稳定发布池、较早截断轨迹和大量重复周期的飞行采样沿用末次迭代。上半程的变化和下半程的平均作用在同一套网络参数上，线上推理保持单头。
- 在稳定池的已发布预留行上，按隐藏单元的输出权重排序，将单元分为四组。每组共同沿本组输出方向线性化，求传感器、工况和骨干预测对隐藏输入的修正。将岭回归步投影到同时保护正、负 NASA 尾部的方向，再在另一半预留行上试探三个步长。要求实际前向计算的均方误差下降、MAE 增幅不超过 0.1%、四个寿命区间的均方误差增幅各不超过 1.8%，两个指数尾的增幅各不超过 1.5%。满足条件才折叠进已有权重矩阵。检查用预留行与此前读出校准有重合，独立检验在全套公开验证及整机切分上完成。
- 同一输入可只含单条传感器观测。训练时的寿命标签、轨迹顺序、额外传感器历史和设备号均无需在线取得。保留 V7 对 V5/V7 已有工件的解码。冻结文件 `engine.py` 的 SHA-256 为 `f5c9af7fd0d76b0fb0b24af2df79cb59d50d14215a84436d2ffef29182d4e32c`。

权重平均实验参考 Izmailov 等人的单模型权重平均工作，本实现直接利用现有 Adam 训练的后半程迭代。按发动机分组检验和并行报告 NASA/方差误差参考 Adeel 对 FD002/FD004 的多种历史对照审计（2026 年 11 月预印本）。因果分割和对终态工件计算摘要借鉴了 AeroMaintain 的开源实验流程。外部 DS02 的少数设备无法代表 N-CMAPSS 各类故障。[权重平均原论文](https://proceedings.mlr.press/r16/izmailov18a.html) · [工况归一化审计](https://arxiv.org/abs/2611.28759) · [AeroMaintain](https://github.com/EfeErim/aeromaintain-ai) · [2026 年 N-CMAPSS 分组校准研究代码与结果](https://zenodo.org/records/21281080)

## 全部公开验证及整机对照

MAE、RMSE 单位为周期。NASA 为每套样本内 V8 与 V5 的指数代价总和之比。公开完整发布条件训练两次，第二次为稳定池。其他数据先后发布设备寿命的 55%、70%、85%、100%。下表采用每条路线最后一次训练的独立验证预测。

| 切分 | 验证样本 / 整机 | V5 RMSE / MAE | V7 RMSE / MAE | V8 RMSE / MAE | NASA V8 / V5 |
|---|---:|---:|---:|---:|---:|
| 公开完整发布 | 23,049 / 106 | 47.287 / 32.946 | 46.915 / 32.870 | 46.920 / 32.852 | 0.9220 |
| 训练集内整机折 1 | 23,777 / 100 | 51.035 / 37.202 | 50.664 / 37.113 | 50.664 / 37.113 | 0.7808 |
| 训练集内整机折 2 | 22,691 / 100 | 49.449 / 36.466 | 49.161 / 36.247 | 49.161 / 36.247 | 0.9023 |
| 外部 N-CMAPSS DS02 | 12,960 / 2 | 7.824 / 5.966 | 7.714 / 5.843 | 7.714 / 5.843 | 0.9691 |

两套整机折按原设备编号模 5 留出，包含 FD001 至 FD004。DS02 使用四台独立训练设备，保留 18 号和 20 号整机验证。复用已有外部特征文件和 CruiseBench 巡航掩码，在 DS02 单独训练。近失效发布识别在整机折最后一轮及 DS02 未开启，三个结果与 V7 相同。整套公开验证中，首轮 V8 RMSE 46.939、MAE 32.971，对应 V5 47.776、33.904。V8 的首轮和稳定轮在 NASA 与 MAE 之间有取舍。

按设备进行 1,200 次有放回配对自助抽样。V8 相对 V5 的 RMSE 差在整套公开、整机折 1、整机折 2 的 95% 区间依次为 [−0.613, −0.116]、[−0.738, −0.050]、[−0.510, −0.050] 周期。公开完整发布的 MAE 差区间为 [−0.332, +0.140]，NASA 相对差区间为 [−27.2%, +4.4%]。公开 RMSE 的改善比 MAE 和 NASA 的点估计更稳定。折 1 的 NASA 区间为 [−28.0%, −5.1%]，折 2 为 [−12.6%, +1.5%]。

## 十轮漂移回放

固定 V5 本地控制器、回放动作计划、候选选择可见行、起始骨干、运行预算和外部留出行，只替换发动机头。schedule 使用公开报告的发布量和阶段顺序，FD001–FD004 分做代理阶段。trace 改变阶段构成及顺序，drift 从各条轨迹的前 55% 开始，逐步释放至终点。以下均为本地代理指标。阶段均值和最低为相对静态骨干的百分比收益，最大回撤为阶段收益相对自身历史最好的下降，越小越好。NASA 为每轮当前阶段的单位样本平均代价，再跨轮、跨种子取平均。

| 协议与种子 | 指标 | V5 | V7 | V8 |
|---|---|---:|---:|---:|
| 开发 schedule 1,3,5 | 阶段均值 / 最低 | 10.33 / 6.57 | 11.17 / 7.06 | 11.39 / 7.25 |
| 开发 schedule 1,3,5 | 最大回撤 / 恢复轮数 | 1.00 / 0 | 3.50 / 0 | 4.15 / 0 |
| 开发 schedule 1,3,5 | NASA | 66,152 | 51,773 | 47,740 |
| 冻结后 schedule 11,14,15,16 | 阶段均值 / 最低 | 10.87 / 3.57 | 13.55 / 5.41 | 13.80 / 5.56 |
| 冻结后 schedule 11,14,15,16 | 最大回撤 / 恢复轮数 | 1.02 / 0.25 | 3.21 / 0 | 5.10 / 0 |
| 冻结后 schedule 11,14,15,16 | NASA | 38,112 | 42,718 | 31,554 |
| 冻结后 trace 12 | 阶段均值 / 最低 / NASA | 16.36 / 6.44 / 10,847 | 16.82 / 10.68 / 10,573 | 16.64 / 10.03 / 10,180 |
| 冻结后 drift 12 | 阶段均值 / 最低 / NASA | 19.96 / 4.89 / 11,411 | 19.41 / 6.33 / 10,444 | 19.50 / 6.51 / 10,313 |

七个 schedule 种子上，V8 的最低收益均优于 V5。四个冻结后种子上，V8 对 V7 两胜两负，V8 的平均回撤较大。冻结后的 schedule 11 与 trace 12 均在第 2、3、9 轮成功接受新候选。生产控制器的最终组合效果需用 V8 的统一端到端回放和平台报告另行判断。

## 消融与效率

| 路线 | 实验结果 |
|---|---|
| 相邻周期创新噪声白化、慢传感器投影、局部核岭回归 | 测试 PCA、慢特征、尾部权重、不同半径/中心数和岭系数。六条新路线在整机折 2 的 NASA 为 V5 的 2.05 至 3.48 倍，全数淘汰。 |
| 固定梯度步数、每个 epoch 换样本 | 整机折 1 NASA 为 V5 的 0.57，折 2 为 0.77，但折 2 的 MAE 36.55 高于 V5 的 36.47；整套公开稳定轮 NASA 为 V5 的 1.02。 |
| 所有发布池取后半程平均；加噪或去掉曲率通道 | 无条件平均在折 2 的完整发布终态 MAE 为 36.50，局部条件未满足时保留末次迭代更好。换样本、噪声、曲率均对验证代价有显著影响。 |
| 四组隐层校准施于所有池 | 宽松正则在整机折 2 的 NASA 达 V5 的 1.089。固定到稳定发布池使该折完整发布保持 V7 结果。 |
| 仅成熟度判定、半权重平均 | 开发 schedule 1/3/5 的最低收益均值为 7.08%，全权重并对稳定池校准为 7.25%。 |

冻结生产头与研究实现分别训练四种发布条件，每种在 600 行上逐项比较，误差小于 1e−10。V5、V7、V8 各自的批量与单条推理在普通行及 48 条工况边界、传感器异常值构造行上对齐，最大绝对误差小于 3.5e−13。CPU 单核、交替顺序、每次 600 行，每组七次取中位数。冻结头按四种条件的每条推理耗时为 46.4、71.2、47.5、44.2 微秒；同台 V5 原实现为 45.7、62.1、43.5、62.5 微秒。V8 与 V7 的运行算子和同条件头大小相同，新发布头 21,088 字节、稳定头 17,920 字节；V8 的迭代平均和稳定期校准均折叠进现有参数。该环境下稳定轮拟合 CPU 约 2.29–2.43 秒，比 V5 的 1.18–1.28 秒长。平台资源分包含完整 Harness 和模型调用，应采用其独立报告。

## 复现

在 `企业赛/V8` 下，设置 `OPENBLAS_NUM_THREADS=1`、`OMP_NUM_THREADS=1` 并运行以下命令。原始结果在服务器忽略目录 `企业赛/work/v8/engine`，包含各轮输出、两侧 NASA、预测误差区间及计时。

```bash
python3 -B engine_study.py probe official v5,v7,maturity,maturityfull,maturitycal,maturityfullcal
python3 -B engine_study.py probe fold2 v5,v7,pca,slow,slowtail,slowtailwide,slowtailwideloose,rank6densewidetail
python3 -B engine_study.py probe DS02 v5,v7,avg,rotate,rotateavg,avgnoise,rotateavgnoise,rotateavgnocurve
python3 -B engine_study.py replay frozen schedule 14
python3 -B engine_study.py replay v5 schedule 14
python3 -B engine_study.py ci official
python3 -B engine_study.py verify maturityfullcal
```
