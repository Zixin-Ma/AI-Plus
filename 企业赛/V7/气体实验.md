# 气体识别 V7 对照实验

企业赛 V5 的正式报告中，气体 A 第一个阶段相对静态基线收益为 −37.60%。V6 提供了已保存的本地试运行。V7 把评估重点放在首批完整发布、一个完整组从候选选择中剔除时的表现，以及发布早期每类只有少量样本时的回撤。下列结果来自服务器公开数据和独立来源的补充数据。

## 冻结的方法

1. **动力学原型覆盖不同响应强度。** 每类最多保留 16 个核中心。对八组传感器的稳态响应取对数并求均值，按这个强度代理在各气体类别内排序，再按等人数分块求中心。每次拟合只读取当前已经释放的训练行。强度代理随背景和浓度共同变化，缺少真实浓度时仍可计算。
2. **物理核强调有区分度的传感器形状。** 每个通道先计算等类别加权的类间与类内方差，以加 0.1 后的方差比取四次方根，并限制上下界。不同传感器共享的响应分量取权重 0.25，全部权重作均方归一化。拟合时将权重并入原有标准差，保留模型文件结构和单次推理开销。
3. **给稀疏的尾部候选共享斜率。** 当样本最少的类别有 2–15 条时，先在各类内部中心化强度和动力学响应，估计共同的一阶响应斜率。每类独立拟合截距，将一次项收缩到共同斜率、二次项收缩到零，三个惩罚系数为 0.01、9、10。最后将系数换回原有坐标。独立候选仍使用独立曲线；样本最少的类低于 2 条时沿用主干回退。这样可以用公开选择集原有的两候选规则选择尾部或独立响应。

2026 年的 MDFE-Net 将互补的传感器表示分成两个分支；本次测试了分别约束各分支的收益。近期跨时段电子鼻复现工作公开了固定协议及代码，因此跨日审计按完整日期报告。漂移校准研究也发现固定门限会让跨日的预测覆盖率收缩，故本实验对所有审计行计算宏 F1。物理特征的稳态/瞬态含义采用数据提供者说明。另以开源 LFDA 实现为参考，做过类内与类间散度投影对照。[MDFE-Net](https://doi.org/10.1021/acssensors.6c00538) · [跨时段复现论文](https://www.sciencedirect.com/science/article/pii/S0026265X26032674) · [作者代码](https://github.com/SuperAIfuture/E-nose/commit/51ceaf593d35f9b97b9b688a5185d37877ad5f4b) · [漂移与校准](https://doi.org/10.1002/cem.70148) · [UCI 采集说明](https://archive.ics.uci.edu/dataset/224/gas%2Bsensor%2Barray%2Bdrift%2Bdataset) · [metric-learn](https://contrib.scikit-learn.org/metric-learn/_modules/metric_learn/lfda.html)

## 首轮与完整组留出

首批 445 条公开训练记录，完整验证集 1,244 条。第一列 F1 使用整份验证集同时做模型选择和评分，反映常规发布流程。后两列先按各类内部 source_index 顺序分八块，每次只用其他七块选头，再评估完整留出块。各块以该块官方静态模型 F1 为参照，计算相对提升，再等权统计。这八组是顺序代理，真实跨日结果见下文。

| 对照 | 完整首批宏 F1 | 八组平均收益 | 八组最低收益 |

## 部署与复算

每类 4、9、16 条及完整 445 行的训练量，各测 tail 与 independent；每组 1,257 条输入包括完整公开验证、零响应、极高/低幅、变号输入。V7 生产批量 logits 与研究实现最大绝对差低于 1.6×10⁻⁷。单条与批量及 V6 旧头回读均通过 1e−9 容差。8 种情况 V6 与 V7 头内数组的总字节数逐项相等。完整首批压缩候选文件为 248,502 → 248,578 字节。在同一 CPU 进程按交错顺序测七轮、每轮 160 条，完整独立头单条耗时中位数 460.7 → 442.5 µs，完整尾部头 226.4 → 225.5 µs，时间会随机器负载波动。生产头与研究实现的另 25 条对应流、250 轮中，候选家族、权重、调用次数、审计指标及每组收益逐轮相同。驱动提示的字节数随 Harness 版本变化，归入整体资源实验。

在仓库根目录激活 ai-plus 环境并设置单线程。下列命令分别生成首批、八组、配对流、外域和部署核验。原始逐轮记录均放在 `企业赛/work/v7/gas/`。流文件名内的 `v6-A` 是复用的测试程序参数，父目录区分真实受测配方。全部开发和验证仅使用本地 CPU。

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 PYTHONDONTWRITEBYTECODE=1
driver=企业赛/V7/gas_study.py
recipe=node+shapeonly+smallpool8
orders=2,4,6,7,10,11,13,14,15,16,17,18,19
for head in base node shapeonly node+shapeonly node+shapeonly+tailpool8 node+shapeonly+localpool8 node+shapeonly+kin4 "$recipe" production; do
  python -B "$driver" "$head" full
  python -B "$driver" "$head" opening
done
for head in base "$recipe"; do
  python -B "$driver" "$head" stream "$orders" schedule trace official fresh drift
done
for head in "$recipe" production; do
  python -B "$driver" "$head" stream 0,3,5,8,12 schedule trace official fresh drift
done
python -B "$driver" "$recipe" external
python -B "$driver" production verify
python -B "$driver" production summary
```

服务器存档的 `choice.json` 记录选定时刻，`summary.json` 汇总 65 对流、完整原生外域与部署证据。汇总同时读取变体消融的完整首轮和八组结果。生产文件 SHA-256 为 `gas.py a2bf2123bd443166a254e5890b7c0a5b02c6287b6258c5a752b1a145d6e77bd6`、`prototype.py b5360dca4ee3df729d81282d9fee76948231ace682b53495b6330e9537ed73f7`。
